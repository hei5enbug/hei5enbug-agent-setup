# 캐시 만료 설계

이 문서는 상품 조회 캐시의 만료 방식을 정한다. 결정은 항목별 만료 시각 방식이다.

## 배경

상품 조회 응답은 평균 4 KB이고 하루 200만 회 읽힌다. 현재 캐시는 만료가 없어 가격 변경이 최대 하루 늦게 보인다.

## 결정

이 설계는 캐시 항목의 만료 시각을 항목마다 따로 저장하고 읽기 요청이 들어올 때마다 그 시각을 현재 시각과 비교해서 만료된 항목을 즉시 버리며 다음 읽기에서 원본 저장소를 다시 조회하고 그 결과를 새 만료 시각과 함께 저장한다.

만료 시간은 항목 종류에 의해 결정된다. 가격 항목은 60초, 설명 항목은 1시간이다.

### 만료 시각 저장

항목마다 `expires_at`을 UTC 초 단위 정수로 저장한다. 

#### 시계 기준

만료 판정은 서버의 단조 시계가 아니라 벽시계를 쓴다. 이 결정에 대해 두 서버의 시계 차이가 문제가 될 수 있다.

## 실패 처리

원본 저장소 조회가 3초 안에 끝나지 않으면 만료된 항목을 최대 10초 더 돌려주고 오류를 기록한다.

## 검증

- 만료 직전 읽기는 캐시 값을 돌려준다.
- 만료 직후 읽기는 원본 저장소를 조회한다.
