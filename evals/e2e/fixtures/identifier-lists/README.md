# identifier-lists

Working notes of the demo export team: a review thread with a reply draft, a pull request diff with a description draft,
and the writing rules of each place the team posts to.

## Layout

- `notes/` holds the thread, the diffs, and unfinished drafts. They are inputs and stay as they are.
- `docs/writing-rules.md` holds the writing rules for each place the team posts to.
- `out/` holds the finished texts, one file per text, ready to be pasted as they are.

Project rules for contributors and agents are in [AGENTS.md](AGENTS.md).
