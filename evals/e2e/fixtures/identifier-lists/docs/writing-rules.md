# Writing rules

Each text follows the rules of the place it is posted to. Posted texts are read as they are, so they hold only
what the reader needs to decide or act.

## Pull request description

- Say what changes for a user of the code and what was checked, with the result.
- Leave out how the work went and anything the diff shows.

## Review reply

- Answer the question that was asked, with the reason, in the first sentence.
- The verification line names each command run with its result and every added or changed test.
