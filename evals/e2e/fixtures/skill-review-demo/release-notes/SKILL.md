# Release notes

Write release notes for the changes the user lists.

1. Start with the heading `# Release notes <version>`.
2. List at most 5 changes, one line each, as bullets.
3. End with an `Upgrade steps` section that names every breaking change, or the single line `No upgrade steps.` when there is none.
