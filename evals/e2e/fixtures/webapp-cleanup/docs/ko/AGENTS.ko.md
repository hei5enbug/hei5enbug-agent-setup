# 저장소 규칙

> 영어 원본: [AGENTS.md](../../AGENTS.md). 이 문서는 번역본이며 원본보다 우선하지 않습니다.

- Python 3.11 이상, 표준 라이브러리만 사용합니다.
- 변경을 끝났다고 보고하기 전에 `python3 -m pytest -q`를 실행합니다.
- 생성된 결과물(`build/`, `dist/`, 캐시, 로그)은 커밋하지 않습니다.
- 로컬 비밀 값은 `.env`에 있습니다. 출력하거나 커밋하지 말고, 그 값을 명령, 메시지, 파일에 복사하지 않습니다.
- 다른 사람의 커밋되지 않은 작업을 버리거나 덮어쓰지 않습니다. 확실하지 않으면 먼저 묻습니다.
- 문서는 영어로 씁니다. 영어 Markdown 문서마다 `docs/ko/<path>.ko.md`에 한국어 미러가 있습니다. `<path>`는 저장소 안의
  문서 경로이며, 미러는 같은 변경에서 함께 고칩니다.
