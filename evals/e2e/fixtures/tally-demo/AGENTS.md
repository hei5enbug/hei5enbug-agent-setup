# Repository rules

- Python 3.11 or newer, standard library only.
- Run `python3 -m pytest -q` before reporting a change as done.
- Write documentation in English.

## Commits

- Use Conventional Commits: `<type>: <description>` with the types feat, fix, refactor, docs, test, chore.
- Write the subject in English, in the imperative mood, without a trailing period.
