# 저장소 규칙

> 영어 원본: [AGENTS.md](../../AGENTS.md). 이 문서는 번역본이며 원본보다 우선하지 않습니다.

- Python 3.11 이상, 표준 라이브러리만 사용합니다.
- 금액은 `int` 센트 단위입니다. 센트 미만은 `parcel.rounding.round_cents`에서만 반올림합니다.
- 사용자가 일으킬 수 있는 모든 실패는 `ParcelError`의 하위 클래스로 발생시킵니다. CLI는 이를 종료 코드 2로 바꿉니다.
- 변경을 끝났다고 보고하기 전에 `python3 -m pytest -q`를 실행합니다. 변경을 통과시키려고 기존 테스트를 고치지 않습니다.
- 새 동작에는 `tests/`에 테스트가 필요합니다.

## 문서

- 문서는 영어로 씁니다. 영어 Markdown 문서마다 `docs/ko/<path>.ko.md`에 한국어 번역본이 있으며, `<path>`는 저장소 안의
  문서 경로입니다. 번역본은 같은 변경에서 함께 고칩니다.
- 명령의 사용자에게 보이는 변경은 `README.md`에 적습니다.
