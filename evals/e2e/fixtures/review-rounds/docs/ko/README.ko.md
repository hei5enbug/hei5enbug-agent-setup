# review-rounds

> 영어 원본: [README.md](../../README.md). 이 문서는 번역본이며 원본보다 우선하지 않습니다.

데모 운영팀의 작업 메모 저장소입니다. 작업 항목, 초안, 검토 지적, 그리고 팀이 올리는 글의 작성 규칙을 담습니다.

## 구성

- `notes/`에는 작업 항목, 변경 메모, 검토 지적, 미완성 초안이 있습니다. 입력이므로 그대로 둡니다.
- `docs/writing-rules.md`에는 팀이 글을 올리는 곳별 작성 규칙이 있습니다.
- `out/`에는 완성한 글이 글마다 파일 하나씩 있으며, 그대로 붙여 넣을 수 있는 상태입니다.

기여자와 에이전트용 프로젝트 규칙은 [AGENTS.md](../../AGENTS.md)에 있습니다. 이 문서의 한국어 미러는
[docs/ko/README.ko.md](README.ko.md)입니다.
