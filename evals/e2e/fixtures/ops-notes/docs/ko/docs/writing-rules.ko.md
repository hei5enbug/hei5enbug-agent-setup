# 작성 규칙

> 영어 원본: [docs/writing-rules.md](../../../docs/writing-rules.md). 이 문서는 번역본이며 원본보다 우선하지 않습니다.

글마다 올리는 곳의 규칙을 따릅니다. 올린 글은 그대로 읽히므로, 독자가 판단하거나 행동하는 데 필요한 내용만 담습니다.

## 이슈 본문

- 증상, 재현 절차, 기대 결과를 적습니다.
- 독자에게 필요할 때만 참고 링크를 걸고, 같은 대상은 한 번만 겁니다. 페이지의 한 절은 그 절이 속한 페이지가 이미
  링크하면 따로 링크하지 않습니다.

## 티켓 코멘트

- 요청에 적힌 완료 기준마다 결과를 한 줄씩 적습니다.
- 작업이 어떻게 진행됐는지와 티켓에 이미 보이는 내용은 뺍니다.

## 채팅 메시지

- 독자에게 무엇이 언제 바뀌는지로 시작합니다.
- 수치는 표나 문장 중 한 곳에만 적고, 둘 다에 적지 않습니다.

## 위키 페이지

- 페이지의 글자 수 한도는 1,500자입니다.
- 링크한 페이지의 내용을 다시 풀어 쓰지 않습니다. 출처는 한 번만 링크하고, 페이지의 다른 링크가 이미 이어 주는
  페이지는 링크하지 않습니다.
