# Writing rules

Each text follows the rules of the place it is posted to. Posted texts are read as they are, so they hold only
what the reader needs to decide or act.

## Issue body

- Give the symptom, the steps to reproduce, and the expected result.
- Link a reference only when the reader needs it, and link each target once. Do not link a page section when the
  page it belongs to already links it.

## Ticket comment

- Report the result of each completion criterion in the request, one line per criterion.
- Leave out how the work went and anything the ticket already shows.

## Chat message

- Start with what changes for the reader and when.
- Give a figure in a table or in prose, never in both.

## Wiki page

- The page has a budget of 1,500 characters.
- Do not restate a linked page. Link each source once, and do not link a page that another link on the page
  already leads to.
