# Repository rules

- Write finished texts for other readers to `out/<name>.txt`. Do not edit files in `notes/`.
- A text follows the rules of the place it is posted to in `docs/writing-rules.md`.

## Documentation

- Write documentation in English. Every English Markdown document has a Korean mirror at
  `docs/ko/<path>.ko.md`, where `<path>` is the document's path in the repository, and the mirror is updated in
  the same change.
- A mirror starts with its title and a quoted line that links the English source and says the mirror is not
  authoritative.
