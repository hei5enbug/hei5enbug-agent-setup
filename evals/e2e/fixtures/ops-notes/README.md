# ops-notes

Working notes of the demo operations team: raw notes, drafts, and the rules for the texts the team posts.

## Layout

- `notes/` holds raw notes and unfinished drafts. They are inputs and stay as they are.
- `docs/writing-rules.md` holds the writing rules for each place the team posts to.
- `out/` holds the finished texts, one file per text, ready to be pasted as they are.

Project rules for contributors and agents are in [AGENTS.md](AGENTS.md). The Korean mirror of this file is
[docs/ko/README.ko.md](docs/ko/README.ko.md).
