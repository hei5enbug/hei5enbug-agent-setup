# stage-notes

The notes and writing rules of a team that runs a data migration, kept as files.

## Layout

- `docs/` holds the migration procedure, the format rules, and the rollout plan, plus the team's writing rules.
- `notes/` holds drafts that wait to be posted. They are inputs and stay as they are.
- `out/` holds the finished texts, one file per text, ready to be pasted as they are.
