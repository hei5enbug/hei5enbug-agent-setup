# plugin-host

> 영어 원본: [README.md](../../README.md)
> 이 문서는 비권위 한국어 번역본이다.

가상의 플러그인 호스트의 세션 컨텍스트를 만들고 `plugin.json`에서 옵션을 읽는다.

## 문서 지도

| 문서 | 목적 |
|---|---|
| [docs/configuration.md](docs/ko/docs/configuration.ko.md) | 옵션과 값. |
| [instructions/routing.md](docs/ko/instructions/routing.ko.md) | 배포 방식이 세션의 동작을 바꾸는 방법. |

테스트는 `python3 -m pytest -q`로 실행한다.
