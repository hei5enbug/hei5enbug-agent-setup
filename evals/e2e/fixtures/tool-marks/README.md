# tool-marks

A small field parser and the working notes of the demo export team.

## Layout

- `parser/` splits a line of comma-separated fields.
- `config/review.yaml` holds the review settings.
- `docs/export-guide.md` describes the export steps.
- `notes/` holds the change notes and the check notes of the team. They are inputs and stay as they are.
- `docs/writing-rules.md` holds the writing rules for each place the team posts to.
- `out/` holds the finished texts, one file per text, ready to be pasted as they are.

Project rules for contributors and agents are in [AGENTS.md](AGENTS.md).
