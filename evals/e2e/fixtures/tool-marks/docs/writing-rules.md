# Writing rules

Each text follows the rules of the place it is posted to. Posted texts are read as they are, so they hold only
what the reader needs to decide or act.

## Pull request description

- Say what the branch changes and which checks ran on the final commit, with each result.
- Leave out what the diff shows.

## Commit message

- The subject says the change. A body is optional and gives only a reason the diff does not show.

## Chat message

- Write for a teammate who reads only this message. Keep it to what the thread needs.
