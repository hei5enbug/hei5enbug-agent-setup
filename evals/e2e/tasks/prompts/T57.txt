재고 서비스에 품목 태그 기능을 넣어줘. 영역이 셋이고 각 영역에 작업이 셋씩이야. 영역별 테스트와 영역을 가로지르는 테스트도 추가해줘.

카탈로그 영역 (inventory/models.py, validators.py, items.py)
- Item에 tags: list[str] 필드를 추가해. 기본값은 빈 목록이고 품목마다 따로 가져.
- inventory/validators.py 에 validate_tag(tag) -> str 를 추가해. 앞뒤 공백을 지우고 소문자로 바꾼 값이 [a-z0-9][a-z0-9-]{0,23} 에 맞아야 하고, 아니면 ValidationError를 내.
- CatalogService.add_tag(sku, tag) -> Item: 태그를 위 규칙으로 정리해서 붙이고 Item.tags는 항상 알파벳순으로 유지해. 이미 있는 태그면 그대로 두고, 서로 다른 태그가 여섯 번째가 되면 "item WIDGET can have at most 5 tags" 형식의 메시지(품목 SKU 사용)로 ValidationError를 내.
- CatalogService.remove_tag(sku, tag) -> Item: 없는 태그면 "item WIDGET has no tag sale" 형식의 메시지로 ValidationError를 내.
- CatalogService.list_items(..., tag=None): tag를 주면 그 태그(같은 규칙으로 정리)를 가진 품목만 돌려줘. CatalogService.tag_counts() -> dict[str, int]: 활성 품목의 태그별 품목 수를 태그 알파벳순 키로 돌려줘.

저장 영역 (inventory/serialization.py, storage.py)
- 품목을 저장할 때 "tags" 목록도 쓰고 다시 불러오면 같은 목록이 돼. "tags"가 없는 예전 품목은 빈 목록으로 읽어.
- SCHEMA_VERSION을 2로 올려. 새로 저장한 파일의 "schema"는 2이고, schema 1 파일도 그대로 불러와. 더 새로운 schema는 지금처럼 StorageError야.
- 불러올 때 "tags"가 문자열 목록이 아니면 StorageError("... is corrupt ..." 기존 메시지 형식)가 나야 하고, 문자열 목록이면 소문자로 바꾸고 중복을 없애 알파벳순으로 정리해서 읽어.

CLI 영역 (inventory/cli.py, formatting.py)
- item tag SKU TAG 는 저장하고 "Tagged WIDGET with sale" 를 출력해. item untag SKU TAG 는 저장하고 "Removed tag sale from WIDGET" 를 출력해. 실패는 지금처럼 stderr에 "error: ..."를 내고 종료 코드 2야.
- item list 에 --tag TAG 옵션을 더하고, 목록 표(formatting.render_items)의 마지막에 TAGS 열을 붙여. 값은 태그를 쉼표로(공백 없이) 이은 문자열이고 태그가 없으면 "-"야.
- item tags 명령은 render_table로 "TAG", "ITEMS" 두 열의 표를 출력해. 행은 활성 품목의 태그별 품목 수이고 태그 알파벳순이야.

영역 사이에서 이어져야 하는 것: CLI로 붙인 태그는 파일에 저장되어 다음 실행에서도 보이고, 저장 파일은 schema 2이며, schema 1 파일에도 CLI로 태그를 붙일 수 있어. 비활성화한 품목은 item list --tag 와 item tags 에서 빠져. README에 새 명령과 옵션을 적고 한국어 미러(docs/ko/README.ko.md)도 함께 고쳐줘.
