- plugin.json: options 는 `auto`, `strict`, `manual` 순서이고 default 는 auto 그대로다. description 에 strict 설명 한 구절을 더한다(ASCII 만).
- 세션 컨텍스트: `Delivery: Strict (`strict`).` 줄을 낸다. 앞뒤 공백과 대소문자 정리, 모르는 값은 auto 줄이라는 기존 동작은 그대로다. MAX_CONTEXT_BYTES 는 올리지 않는다.
- instructions/routing.md: auto 와 manual 사이에 `- `strict`: ...` 항목을 넣어 실패하면 멈추고 원인을 보고한다고 쓴다.
