# 후보 검증 기록

> 영어 원본: [verification.md](verification.md)
> 이 문서는 사람이 읽기 위한 비권위 한국어 미러다. 실행 지침으로 사용하지 않는다.

사용자는 후보까지만 준비하도록 선택했다. 소스 후보를 완성하고 로컬 패키지를 만들었으며, 기존 등록 스킬과
`0.6.0` 매니페스트가 기본값이다. 이 기록은 완료한 로컬 검사와 교체 전에 필요한 실제 동작·무저하 근거를 구분한다.

패키지 소스는 형제 스킬의 실행 파일에 의존하지 않는다. 기존 패키저가 포함한 테스트는 개발용 자료다.
제외된 평가 입력이 필요한 테스트는 저장소의 소스에서 실행한다.

## 제한된 실제 Codex 관측

최종 후보와 기준 버전으로 읽기 전용 작업 두 개를 실제 로컬 도구 호출과 함께 실행했다.
명령에는 `gpt-5.6-luna`, `xhigh`를 지정했다. 이벤트는 사용량을 보고했지만 실제 모델 ID는 다시 나오지
않아 null로 남았다. 명시한 경로를 사용하는 CLI 시험이며 설치 스킬 탐색이나 사람과의 실제 질문 세션은
아니다. 최종 사례별 한 쌍뿐이므로 채택 벤치마크가 아닌 관측값이다.
[시험 결과](trial-results.json)에 정확한 실행 소스 해시와 사용량을 기록했다.

| 사례 | 기존 시간 | 후보 시간 | 기존 보고 입력/출력 토큰 | 후보 보고 입력/출력 토큰 |
|---|---:|---:|---:|---:|
| 읽기 전용 frontier 메타데이터 | 78.494초 | 58.137초 | 149,356 / 3,022 | 94,927 / 2,317 |
| 필수 점수 참조 누락 | 20.235초 | 29.686초 | 26,714 / 708 | 57,558 / 1,223 |

최종 frontier 답변에서 후보는 열려 있고 선행 조건·잠금이 없는 두 티켓을 정확히 식별했다.
숫자 순서상 Backoff Policy를 먼저 고르고 실제 파일 링크를 썼다. 지도 입력의 모든 바이트가 보존됐고
잠금을 만들지 않았다. 기존 버전은 인터뷰 금지와 메타데이터 적격 여부를 섞어 설명한 뒤 두 티켓 모두
메타데이터상 선행 조건이 없다고 덧붙였다.

최종 참조 누락 사례에서 후보는 누락된 영어 점수 파일을 지목하고 점수 평가·질문 전에 멈췄다.
한국어 미러를 대신 사용하지 않았다. 관측된 한 쌍에서 이 경로는 기존보다 느렸고 보고된 입력·출력 토큰도
더 많았다. 일괄적인 효율 향상이나 결과물 품질 보장을 주장하지 않는다.

## 진단 이력과 남은 근거

첫 frontier 진단은 세 쌍이었다. 도중 한 후보 스냅샷이 바뀌어 묶음 시간 통계를 비교 근거에서 제외했다.
답변에서는 frontier 집합과 첫 선택 티켓을 잘못 구분하는 문제가 나왔다. 일부 실행은 필수 지도 참조를
읽기 전에 진입점과 지도 내용을 함께 읽기도 했다. 실행기는 이제 모든 실행 전에 지침 전체를 고정하고
진입점을 먼저 단독으로 읽도록 요구한다.

다음 frontier 예비 시험에서는 집합 구분이 바로잡혔지만 링크에 `...` 자리표시자가 남았다.
후보는 실제 경로를 요구하도록 보완했다. 참조 누락 예비 시험도 수행했다. 이후 공통 진입점과 상세 참조의
중복을 줄이고 최종 두 사례를 비교했다. 스냅샷이 섞인 진단을 포함한 14회 실행은 모두 trial-results.json에
구분해 남겼다. 최종 두 비교의 고정 실행 소스는 전달한 후보와 일치한다.

작성 세션이 최종 답변과 관련 도구 동작을 작업 요청·원본 메타데이터와 비교했다. 독립 채점이나 모든 필수
동작의 증명은 아니다. Claude Code Sonnet/high, 실제 사람 질문, 엄격한 종료, 지도 쓰기 경합·복구,
시안 반응, 탐색 비교는 미검증이다. 사람 UI 평가는 사용자 요청으로 미뤘다.
참조 누락 결과도 이 관측을 성능 기준 통과로 볼 수 없게 한다.

기본 스킬로 전환하기 전에 README.md와 coverage.md의 비교를 마쳐야 한다.
좋은 평균이나 적은 소스 바이트가 한 중요 경로의 실패를 상쇄하지 않는다.
