# 토큰 및 컨텍스트 효율 개선 실행 기록

> 영어 원본: [execution-results.md](execution-results.md)
> 이 문서는 사람이 읽기 위한 비권위 한국어 미러다. 실행 지침으로 사용하지 않는다.

이 기록은 개선안의 성능·품질 무저하 기준에 따른다. `B0`는 커밋
`72f66ac69cf02ac7b7f64bfba0a11adc8736ed04`이다. Markdown 파일이 짧아지거나
단일 프롬프트의 바이트 수가 줄었다고 해서 스킬 전체 실행 비용이 줄었다고 보지 않았다.
원본, 변경 후보, 평가 입력, 검사 결과를 비교한 뒤 유지 여부를 결정했다.
대응 실행별 [실제 호스트 시험 수치](trial-metrics.json)에는 프롬프트와 답변 텍스트를 넣지 않았다.

## 평가 범위와 한계

새 평가 자료는 Deep Interview, 다이어그램, 커밋 제목 추천, 결정 맵,
Confluence 원문·업데이트, 문장 다듬기, 설계 검토, 토론 복구, 새로고침,
OmO 설정을 다룬다. OmO 입력 생성기는 고정한 상류 `dev` 리비전
`c18ab758961b88bc07f7578ddcbcb286810a524f`의 필수 파일 20개와 조건부 파일
13개를 검증했다. 상류 프로젝트의 소스 코드는 이 저장소로 복사하지 않았다.
Confluence의 로컬 연결기 응답 입력은 모의 자료이며 호스팅된 페이지에 쓰지 않았다.
사용자가 실제 질문 UI에서 답할 운영자로 참여하지 않았으므로, 이에 의존하는 후보는 B0로 유지했다.

개발 검사도 통과했다. 스킬 11개 모두 `quick_validate.py`, 전체 Python 테스트,
Node 다이어그램 렌더러 테스트 10개를 실행했다. 평가 사례 103개가 모두 파싱되며
명시된 로컬 입력 경로도 존재한다. 계획 문서의 로컬 링크가 유효하고 영어/한국어
미러 검사가 통과했으며 `git diff --check`에 공백 오류가 없다.

구조 검사, 파일 크기, 제한된 실제 호스트 실행만으로 결과물 품질이나 토큰 절감을
보장하지 않는다. B0에 남은 항목은 대표 작업과 누락된 실제 호스트 기능을 갖춘
별도 평가에서 다시 검토할 수 있다.
