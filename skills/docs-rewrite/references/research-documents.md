# Rewriting research and verification documents

These are the research-document rules to apply in a rewrite.

- Delete a phrase that only signals importance and state the confirmed fact directly.
- When a pointing phrase such as "이것" or "해당 결과" could refer to more than one thing, use the name only if
  the source settles which thing it means. Otherwise, keep the phrase and report the unresolved reference as
  described in the skill's Ambiguity section.
- Keep existing section headings. When a heading clearly states a conclusion as a sentence, recommend a short
  noun phrase naming the section's subject in the notes. Apply the heading change when the user asks for it.
