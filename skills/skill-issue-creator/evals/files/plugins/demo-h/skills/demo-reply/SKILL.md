# Demo Reply

Follow `instructions/shared-writing.md` for every reply this plugin writes.

1. Read the ticket and the resolution notes.
2. Write a short reply that says what was done and what the customer should do next.
3. Include only the identifiers the reader needs to act.
4. Show the draft to the user before it is posted.
