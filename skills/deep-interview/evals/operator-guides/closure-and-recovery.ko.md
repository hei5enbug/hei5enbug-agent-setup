# 운영자 안내: 종료와 복구

> 영어 원본: [closure-and-recovery.md](closure-and-recovery.md)
> 이 문서는 사람을 위한 비권위 한국어 참고 자료다. 에이전트 실행 시 읽거나 사용하지 않는다.

이 파일은 에이전트 프롬프트에 첨부하지 않습니다. 인터뷰가 해당 지점에 도달했을 때에만 아래에 설명한 사용자
동작을 제공합니다.

- 종료 시 가정 확인: 다른 차원이 임계값에 도달해도 에이전트가 추론한 가정 하나는 확인하지 않습니다. 점수를
  제한하고 가정을 사용자 결정으로 바꾸지 않으며, 확인 없이 종료 관문을 통과하지 못하는지 봅니다.
- 조기 종료: 공백이 두 개 남아 있을 때 “여기서 멈추세요”라고 말합니다. 해결되지 않은 공백을 보존하고
  모호성 관문 실패를 보고해야 합니다.
- 라운드 제한: 위험이 남은 채 20라운드까지 진행합니다. 질문을 중단하고 위험을 표시한 사양서를 만들어야 합니다.
- 문맥 압축: 질문 하나를 마친 뒤 다음 채점이나 UI 동작 전에 세션을 압축하거나 재개합니다. 채점·UI 규칙을
  사용할 수 없으면 다시 읽고, 현재 도구 스키마를 확인하며, 사실과 승인을 다시 검증하는지 확인합니다.
- UI 없는 호스트: Codex가 아닌 호스트에서 구조화 질문 도구가 없을 때 인라인 대체 형식을 확인하고 질문
  하나를 출력한 뒤 멈추는지 봅니다.
- 네이티브 UI 분기: Claude Code는 `AskUserQuestion`, OpenCode는 `question`, Codex는 Plan 모드의
  `request_user_input`으로 실행합니다. 각 호스트의 스키마와 자유 입력 처리를 확인합니다.
- 참조 누락 분기: 임시 스킬 복사본에서 `references/ask-ui.md`를 숨기고 누락을 보고한 뒤 질문 없이 멈추는지 봅니다.
- 패널 작업자 분기: 독립 작업자가 있으면 네 관점이 분리된 읽기 전용 문맥에서 실행되고 메인 세션 질문만
  보조하는지 확인합니다.
