# 심층 인터뷰 자동 조사: 그린필드

> 영어 원본: [auto-research-greenfield.md](auto-research-greenfield.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

심층 인터뷰 절차로 `research: true`가 붙은 그린필드 질문 하나를 평가한다.

플러그인 세션 규칙이 적용되면 메인 인터뷰 세션이 후보를 구성하고 순위를 매기며 추천한다.
범위가 정해진 공개 사실 질문 하나는 호스트 에이전트 규칙과
[공유 라우팅 계약](../../../instructions/model-routing.md)에 따라 검증된 researcher에게 맡길 수 있다.
researcher는 아래 후보 JSON 대신 근거와 누락된 정보를 반환한다. 메인이 그 근거와 확정된 인터뷰 결정을 결합한다.
플러그인 규칙이 없으면 호스트가 지원하는 독립 작업자나 순차 대체 경로의 읽기 전용 아키텍트 프롬프트로 유지한다.
플러그인 규칙 아래에서는 아키텍처 또는 수용 결정을 위임하지 않는다.

물려받은 컨텍스트는 읽기 전용 배경이다. 코드나 파일을 수정하고 프로젝트 또는 인터뷰 상태를 바꾸고
포매터를 실행하고 다른 워크플로에 인계하거나 구현하지 않는다. 물려받은 컨텍스트, 표시된 질문,
이전 결정, 토폴로지·온톨로지 메모, 확인된 제약과 사용할 수 있는 읽기 전용 조사만 사용한다.

상위 인터뷰 프롬프트에 넣을 수 있도록 답변을 간결하게 유지한다.

## 작업

질문의 후보 답 2개에서 3개를 순위대로 반환한다. 후보는 구체적이고 서로 다르며 확인된 제약과 일치하고,
답변 선택지나 다음 소크라테스식 질문의 컨텍스트로 쓸 수 있어야 한다.

## 응답 형식

다음 JSON 객체만 반환한다.

```json
{
  "status": "answered",
  "candidates": [
    {
      "rank": 1,
      "answer": "간결한 후보 답.",
      "rationale": "후보가 컨텍스트와 확인된 제약에 맞는 이유.",
      "risks_or_tradeoffs": "후보의 주요 위험, 장단점 또는 주의점.",
      "confidence": "high|medium|low"
    }
  ],
  "recommendation": "가장 좋은 후보와 먼저 제안할 이유를 밝힌 한 문장.",
  "follow_up_gap": "사용자가 더 확인해야 할 불확실성을 밝힌 한 문장."
}
```

- 컨텍스트가 뒷받침하면 `candidates`에 항목 2개 또는 3개를 둔다.
- `rank`는 1부터 시작해 1씩 증가한다.
- `confidence`는 `high`, `medium`, `low` 중 하나다.
- 모든 이유는 프롬프트의 컨텍스트, 확인된 제약 또는 저장소 사실을 인용한다.

## 대체 처리

의미 있는 후보를 2개 이상 만들 수 없으면 `follow_up_gap`에서 알린다.
방어 가능한 후보 하나가 있을 때만 confidence `low`로 반환하고 누락된 컨텍스트를 밝힌다.
확실성을 지어내지 않는다.
