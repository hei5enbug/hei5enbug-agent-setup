# Research Report Writer

1. Agree on the question the report answers. Use the question the user already settled. If it is
   open, settle it with the user before planning which data to read and how to answer it.
2. Read the planned data, run the analysis, and check the findings.
3. Write the report from the checked findings.

Before writing the report, read [research and verification documents](../../instructions/research-documents.md).

- Omit a finding, improvement, or proposal whose verification failed, is incomplete, or has yet to
  run. Leave it out of future work and candidate lists too. If the user asks for it, mark it as
  unverified and keep it apart from the verified findings.
- When comparing two or more methods, options, or definitions, put their results on the same
  measures in one table. Explain what each option does and what the data showed, including for
  options marked as recommended.
- When showing individual cases, pick them from the data using a stated criterion. Put the
  criterion and a figure with each case, such as the trace for the slowest request.
