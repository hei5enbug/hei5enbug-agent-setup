# 논리 프로토타입

> 영어 원본: [prototype-logic.md](prototype-logic.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

질문이 비즈니스 로직, 상태 전환 또는 데이터 형태에 관한 것이면 작은 대화형 터미널 프로그램을 만든다.

## 절차

1. 프로토타입 위쪽이나 가까운 README에 질문을 쓴다.
2. 저장소의 기존 언어와 작업 실행기를 사용한다.
3. 결정 로직을 작은 순수 인터페이스 뒤에 둔다.
   - 개별 동작에는 reducer
   - 합법적인 동작이 현재 상태에 달리면 상태 머신
   - 상태 없는 변환에는 순수 함수
   - 지속되는 내부 상태가 꼭 필요하면 작은 모듈
4. 터미널 입력과 렌더링을 인터페이스 밖에 둔다.
5. 입력할 때마다 전체 현재 상태와 사용 가능한 동작을 렌더링한다.
6. 가능하면 전체 인터페이스를 터미널 화면 하나에 표시한다.
7. 시작 명령 하나를 제공한다.

테스트를 추가하거나 실제 데이터베이스를 연결하거나 질문보다 넓게 일반화하거나 터미널 셸을 운영 코드로
배포하지 않는다. 검증된 순수 로직은 나중에 실제 구현의 근거로 사용할 수 있다.
