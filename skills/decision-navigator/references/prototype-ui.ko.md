# UI 프로토타입

> 영어 원본: [prototype-ui.md](prototype-ui.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

질문이 레이아웃, 정보 계층 또는 시각적 상호작용에 관한 것이면 구조가 서로 다른 UI 변형을 여러 개 만든다.

## 배치

실제 탐색, 데이터 밀도와 주변 레이아웃을 사용하도록 기존 페이지에 변형을 넣는다.
알맞은 기존 페이지가 없을 때만 폐기할 route를 만든다.

## 절차

1. 질문을 쓰고 변형 3개를 기본으로 만든다. 5개를 넘지 않는다.
2. 색이나 문구만이 아니라 구조와 주요 affordance가 다르게 한다.
3. 프로젝트의 구성 요소와 스타일 시스템을 재사용한다.
4. `?variant=A` 같은 공유 가능한 URL 매개변수로 변형을 선택한다.
5. 이전, 현재, 다음 컨트롤이 있는 작은 고정 전환기를 추가한다.
6. 텍스트 입력에 초점이 없으면 왼쪽과 오른쪽 화살표 키를 지원한다.
7. 운영 빌드에는 전환기가 나타나지 않게 한다.
8. 사람에게 URL을 주고 비교 의견을 기다린다.

선택 뒤에는 채택한 변형과 거절한 변형에서 유용했던 부분을 기록한다.
전환기와 탈락한 변형을 메인 코드에서 제거한다. 프로토타입 코드에는 운영 테스트와 오류 처리가 없으므로
채택한 아이디어를 배포하기 전에 다시 작성하거나 강화한다.
