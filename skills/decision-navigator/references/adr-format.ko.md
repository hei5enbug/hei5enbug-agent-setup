# ADR 형식

> 영어 원본: [adr-format.md](adr-format.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

ADR은 `docs/adr/` 아래 `0001-event-sourced-orders.md` 같은 순차 이름으로 저장한다.
저장소가 컨텍스트별 `docs/adr/` 구조를 이미 사용하면 해당 컨텍스트의 디렉터리를 사용한다.

## 최소 템플릿

```markdown
# 짧은 결정 제목

배경, 결정과 선택 이유를 설명하는 한 문장에서 세 문장.
```

미래 독자에게 도움이 될 때만 상태, 거절한 선택지 또는 결과를 추가한다.
기존 ADR의 가장 큰 번호를 찾아 하나 증가시킨다.

결정이 있다는 이유만으로 ADR을 만들지 않는다. [도메인 모델링](domain-modeling.ko.md)의 세 가지 조건을 사용한다.
