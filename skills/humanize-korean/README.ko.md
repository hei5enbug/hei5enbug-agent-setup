# 한국어 문체 다듬기

> 이 문서는 한국어 사용자를 위한 참고 안내서입니다. 에이전트가 스킬을 실행할 때는
> 영어로 작성된 `SKILL.md`와 영어 참고자료만 사용합니다. 두 문서의 내용이 다르면
> `SKILL.md`를 기준으로 합니다.

## 목적

뜻을 바꾸지 않으면서 번역투, 틀에 박힌 연결어, 반복되는 문장 구조, 지나친 수동태,
명사형 표현 등을 자연스러운 한국어로 다듬습니다.

다음 내용은 사용자가 따로 바꾸라고 하지 않는 한 그대로 유지합니다.

- 사실, 주장, 불확실성, 인과관계, 관점
- 수치, 날짜, 단위, 고유명사, 제품명, 인용문
- 글의 장르, 독자, 높임 수준, 서술 관점
- 의미가 있는 제목, 문단, 목록, 표, 링크

새로운 사례나 근거, 비유, 의견, 결론은 덧붙이지 않습니다. 조심스럽게 표현한 내용을
더 확실한 주장으로 바꾸지도 않습니다.

## 실행 방식

기본적으로 다음 순서로 처리합니다.

1. 글의 장르와 말투를 파악합니다.
2. 바꾸면 안 되는 수치, 이름, 인용문 등을 먼저 확인합니다.
3. 실제로 어색한 부분만 찾습니다.
4. 해당 부분만 작게 고칩니다.
5. 원문과 대조해 뜻이 달라지지 않았는지 확인합니다.
6. 지나치게 꾸민 표현이나 과도한 수정은 되돌립니다.

이미 자연스러운 글은 억지로 고치지 않습니다.

## 선택 사항

| 입력 | 동작 |
|---|---|
| `장르: 칼럼` | 칼럼의 형식과 말투를 유지합니다. |
| `장르: 리포트` | 보고서의 형식과 말투를 유지합니다. |
| `장르: 블로그` | 친근한 글의 흐름을 유지합니다. |
| `장르: 공적` | 공식적인 말투를 유지합니다. |
| `강도: 보수` | 확실히 어색한 부분만 고칩니다. |
| `강도: 기본` | 뚜렷한 문제와 반복되는 문제를 고칩니다. |
| `강도: 적극` | 문장 흐름과 구조까지 넓게 살핍니다. |
| `--strict` 또는 `정밀 모드` | 뜻 보존과 자연스러움을 따로 한 번 더 점검합니다. |

이전 표현인 `5인 파이프라인`도 정밀 검토 요청으로 처리합니다. 다만 실제로 다섯
에이전트를 호출한다는 뜻은 아닙니다.

입력이 8,000자를 넘으면 정밀 검토를 자동으로 적용합니다. 이때도 별도 작업 폴더나
결과 파일을 만들지 않습니다.

## 후속 요청

| 요청 | 처리 범위 |
|---|---|
| `이 문단만` | 지정한 문단만 다시 다듬습니다. |
| `연결어만 다시` | 연결어와 관련된 부분만 고칩니다. |
| `2차 윤문` | 직전 결과에서 남은 문제만 다시 살핍니다. |
| `강도를 보수로 바꿔줘` | 새 강도만 적용하고 다른 부분은 건드리지 않습니다. |
| `장르를 칼럼으로 바꿔줘` | 사실과 관점은 그대로 두고 장르 표현만 조정합니다. |

## 결과 형식

기본 결과는 다듬은 글입니다. 사용자가 설명을 요청했을 때만 주요 수정 종류와 남은
주의점을 짧게 덧붙입니다.

사용자가 파일 출력을 요청하거나 제공한 파일을 직접 고쳐 달라고 하지 않는 한 작업
폴더, 보고서, 측정 파일을 만들지 않습니다. 실제로 측정하지 않은 변경률, 등급, 탐지
점수도 표시하지 않습니다.
