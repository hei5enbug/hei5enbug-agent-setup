검색 응답 속도 개선 검토

검색 결과 캐시를 도입하면 검색 응답 시간의 p95가 줄어드는지 검토했다.

결과

시험 환경에서 검색 응답 시간의 p95는 820ms에서 410ms로 줄었다. 운영 환경에서는 아직 측정하지 않았다.

검증 방법

같은 검색어 1,000개를 캐시 적용 전과 후에 각각 3번 실행했다. 캐시가 비어 있는 첫 실행은 비교에서 제외했다.

  1. 지난주 검색 로그에서 검색어 1,000개를 무작위로 뽑았다.
  2. 캐시를 끈 상태에서 검색어 목록을 3번 실행하고 각 응답 시간을 기록했다.
  3. 캐시를 켠 상태에서 같은 목록을 3번 실행하고 각 응답 시간을 기록했다.
  4. 두 번째와 세 번째 실행의 응답 시간을 합쳐 p50과 p95를 계산했다.

시험 환경

시험 서버 2대를 사용했다. 각 서버는 4 vCPU와 16GB 메모리를 가진다.

의견

제안: 운영 환경에서 1주일 동안 캐시를 켜고 p95를 다시 측정한다.
