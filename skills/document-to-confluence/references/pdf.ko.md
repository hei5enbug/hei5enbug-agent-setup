# PDF 원본

> 영어 원본: [pdf.md](pdf.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

텍스트 PDF, 레이아웃 PDF와 스캔 PDF에 이 어댑터를 사용한다.
PDF는 의미 구조보다 모양을 안정적으로 저장하므로 변환 전에 읽기 순서를 정한다.

## 원본 분류

대표 페이지를 검사하고 원본을 분류한다.

| 유형 | 주 추출 방식 |
|---|---|
| Tagged PDF | 태그 트리를 사용하고 렌더링 페이지와 대조한다. |
| 텍스트 PDF | 위치와 함께 텍스트를 추출하고 의미 블록을 복원한다. |
| 레이아웃 PDF | 텍스트 위치와 열, 표, 캡션의 시각 검사를 결합한다. |
| 스캔 PDF | 문서 언어로 OCR을 실행하고 불확실한 텍스트를 페이지 이미지와 대조한다. |

파일이 암호화되거나 손상됐으면 정확한 제한을 알리고 접근 가능한 원본을 요청한다.
문서 보호를 우회하지 않는다.

## 읽기 순서와 반복

텍스트를 합치기 전에 열, 사이드바, 캡션, 각주와 페이지 간 이어짐을 결정한다.
반복 머리말, 꼬리말과 페이지 번호는 페이지 장식임을 확인한 뒤에만 제거한다.
모든 정규화 블록에 페이지와 영역 위치를 둔다.

근거 없이 시각적으로 가깝다는 이유로 관계를 만들지 않는다. 캡션은 정확한 이미지나 표에 연결하고
각주 표식은 해당 주석에 연결한다.

## 표와 이미지

렌더링 PDF를 보면서 표의 행, 열, 제목, 병합 셀과 페이지 간 이어짐을 확인한다.
추출로 표가 평면화되거나 셀이 모호해지면 보이는 근거로만 복원하고 미해결 셀은 사용자 확인 대상으로 둔다.

유용한 그림을 충분한 해상도로 추출하고 캡션과 대체 설명이 있으면 보존한다.
추출이 불가능하고 사용자가 제한을 받아들인 경우가 아니면 접근 가능한 텍스트를 전체 페이지 스크린샷으로
대체하지 않는다.

## OCR과 내용 일치

OCR 엔진, 언어와 처리한 페이지를 기록한다. 신뢰도가 낮은 영역, 이름, 식별자, 수식, 수치, 날짜와 단위를
페이지 이미지와 대조한다. 불확실한 OCR 텍스트를 조용히 수정하지 않는다.

게시 전에 페이지 범위, 블록 수, 표, 그림, 주석과 오류 위험이 큰 정확한 텍스트를 비교한다.
