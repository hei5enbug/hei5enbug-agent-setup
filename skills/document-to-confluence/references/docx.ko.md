# DOCX 원본

> 영어 원본: [docx.md](docx.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

Microsoft Word DOCX 파일에 이 어댑터를 사용한다.
스타일, 관계와 포함된 에셋을 보존하는 구조 인식 파서나 변환기를 우선한다.

## 콘텐츠 선택

본문 순서대로 보이는 문서 콘텐츠를 추출한다.

- 제목과 제목 스타일
- 문단과 문자 서식
- 중첩된 번호 목록과 글머리 기호 목록
- 표, 병합 셀과 캡션
- 하이퍼링크, 북마크, 상호 참조, 각주와 미주
- 캡션과 대체 텍스트가 있는 인라인·플로팅 이미지
- 문서 콘텐츠를 담은 머리말과 꼬리말

변경 추적과 댓글이 있고 게시 페이지에 승인된 텍스트, 원본 텍스트 또는 검토 마크업 중 무엇을 사용할지
요청에서 정하지 않았을 때만 처리 방법을 질문한다. 숨긴 텍스트, 문서 속성, 매크로 또는 포함된 파일은
기본적으로 게시하지 않는다.

## 변환 동작

문단 스타일로 계층을 정한다. 시각적인 글자 크기만으로 제목 수준을 판단하지 않는다.
번호가 순서나 식별을 전달하면 자동 번호를 보존한다. 문서 패키지에서 링크와 미디어의 관계 대상을 해석한다.

텍스트 상자, 도형, 수식, SmartArt와 포함된 객체를 특수 블록으로 취급한다.
파서가 보존하지 못하면 사용할 수 있는 렌더러나 오피스 앱을 사용한다.
이미지로 바꿔야 하면 접근 가능한 캡션이나 대체 텍스트를 유지하고 하향 변환을 기록한다.

## 내용 일치 검사

도구가 제공하면 문서 통계와 정규화 블록 목록을 비교한다. 제목, 목록 번호, 표 span, 링크, 주석과
모든 특수 블록을 검사한다. 게시 직전에 DOCX 파일 개정이 바뀌지 않았는지 확인한다.
