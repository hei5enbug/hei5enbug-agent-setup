# 공통 문서 모델

> 영어 원본: [document-model.md](document-model.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

Confluence 본문을 만들기 전에 지원되는 모든 원본을 이 논리 모델로 정규화한다.
모델은 작업 표현이며 필수 파일 형식이 아니다.

## 문서 필드

원본이 제공하면 다음 문서 수준 값을 기록한다.

| 필드 | 의미 |
|---|---|
| `title` | 게시할 페이지 제목 |
| `language` | OCR, 글꼴 선택과 문장 경계에 사용할 언어 |
| `source_revision` | 안정적인 원본 식별 정보와 최신 상태 표식 |
| `scope` | 문서 전체 또는 선택한 페이지, 섹션, 탭 |
| `metadata` | 작성자, 생성일, 수정일과 사용자가 승인한 보이는 메타데이터 |
| `blocks` | 순서가 있는 최상위 콘텐츠 블록 |
| `assets` | 블록이 참조하는 이미지, 파일과 다이어그램 출력 |
| `omissions` | 위치와 이유를 포함해 의도적으로 제외한 원본 콘텐츠 |
| `uncertainties` | 확인이 필요한 읽기 불가 또는 모호한 원본 영역 |

사용자가 범위에 포함하지 않으면 숨긴 속성, 개정 기록, 댓글, 변경 추적 또는 주석을 게시하지 않는다.

## 블록 필드

각 블록에는 유형, 순서가 있는 콘텐츠와 안정적인 원본 위치가 필요하다.
Markdown 제목, HTML 요소 경로, PDF 페이지와 영역, DOCX 문단이나 표 위치 또는 Google Docs 탭과
인덱스 같은 원본 고유 위치를 사용한다.

지원되는 논리 블록 유형은 다음과 같다.

- 수준과 텍스트가 있는 제목
- 인라인 run이 있는 문단
- 중첩 항목이 있는 순서 목록 또는 비순서 목록
- 인용, 콜아웃 또는 코드 블록
- 제목 역할, 행, 열, span과 캡션이 있는 표
- 에셋 참조, 캡션과 대체 텍스트가 있는 이미지 또는 다이어그램
- 첨부 파일 링크
- 참조 블록과 연결된 각주 또는 미주
- 의미가 있는 명시적인 페이지 또는 섹션 나눔

인라인 run은 텍스트, 강조, 코드, 링크 대상과 줄바꿈 의도를 보존한다.
시각 좌표만으로 의미 순서를 표현하지 않는다.

## 불변 조건

- 블록 순서는 원본의 읽기 순서를 따른다.
- 제목 수준은 변환이 만든 빈 단계 없이 계층을 보존한다.
- 목록은 중첩, 순서와 번호에 의미가 있을 때 번호를 보존한다.
- 표는 셀 텍스트, 제목 역할, 행과 열 관계와 병합 셀 span을 보존한다.
- 링크 대상을 바꿔야 해도 레이블과 대상 의도를 보존한다.
- 이미지는 캡션, 대체 텍스트와 주변 콘텐츠와의 관계를 보존한다.
- 각주는 참조와 연결된 상태를 유지한다.
- 모든 제외와 불확실성은 원본 위치를 가리킨다.

## 내용 일치 목록

본문을 만들기 전에 적용할 수 있는 원본 구조의 수를 센다.
만든 뒤 같은 수를 비교하고 모든 예외를 검사한다.

| 구조 | 최소 비교 |
|---|---|
| 제목 | 텍스트, 수준과 순서 |
| 문단 | 텍스트와 문단 경계 |
| 목록 | 항목 수, 중첩과 순서 |
| 표 | 표 수, 크기, 제목, span과 셀 텍스트 |
| 링크 | 레이블, 대상과 해결되지 않은 대상 처리 |
| 이미지와 다이어그램 | 에셋 수, 캡션, 대체 텍스트와 위치 |
| 각주 | 참조 수와 주석 텍스트 |

개수는 누락된 구조를 드러내지만 의미가 같음을 증명하지 않는다.
게시 전에 정규화 모델을 원본과 대조해 읽는다.
