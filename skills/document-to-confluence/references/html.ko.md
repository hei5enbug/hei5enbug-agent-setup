# HTML 원본

> 영어 원본: [html.md](html.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

HTML 파일, 조각, 내보낸 웹 페이지와 접근이 승인된 렌더링 웹 콘텐츠에 이 어댑터를 사용한다.
원본 HTML은 입력이며 `references/confluence-body.md`가 출력 본문을 정의한다.

## 안전한 캡처

신뢰하지 않는 스크립트를 실행하지 않고 정적 HTML을 파싱한다.
사용자 승인 없이 문서나 에셋을 외부 렌더러에 전송하지 않는다.
의미 있는 콘텐츠가 스크립트 실행 뒤에만 나타나면 승인된 브라우저 기능을 사용하고 조회 시간과 페이지
상태를 기록한다. 캡처할 수 없는 콘텐츠를 알린다.

## 의미 구조 추출

시각 좌표보다 의미 요소와 접근성 데이터를 우선한다.

- 제목과 레이블이 있는 영역에서 계층을 얻는다.
- 문단, 목록, 인용, 코드, 표, 링크, 그림, 캡션과 대체 텍스트를 보존한다.
- `aria-label` 같은 접근성 텍스트는 보이는 의미를 나타낼 때만 사용한다.
- 요청 범위 밖의 탐색, 쿠키 배너, 컨트롤과 앱 장식을 제외한다.
- 의미 있는 `pre` 공백과 명시적인 줄바꿈을 보존한다.
- CSS 배경 이미지는 문서 의미를 전달할 때만 캡처한다.

CSS는 의미 있는 그룹이나 순서를 표현할 수 있다. 스타일이 읽기 순서를 바꾸거나 콘텐츠를 숨기거나
pseudo-element 텍스트를 만들거나 일반 컨테이너를 표나 콜아웃으로 바꾸면 렌더링 페이지를 검사한다.
스크립트, 스타일시트, 이벤트 핸들러, 폼 또는 활성 embed를 Confluence에 복사하지 않는다.

## 링크와 에셋

상대 URL은 원본 base URL이나 파일 위치를 기준으로 해석한다. 접근이 승인되고 대상에서 재사용을 허용할
때만 원격 에셋을 내려받는다. 링크가 안정적이고 페이지 독자가 접근할 수 있으면 원본 링크를 유지한다.
조회하거나 게시할 수 없는 에셋을 기록한다.

## 내용 일치 검사

보이는 원본 블록을 정규화 블록 목록과 비교한다. 제목, 문단, 목록, 표 크기, 링크, 그림, 캡션과 의미 있는
줄바꿈을 확인한다. CSS가 레이아웃에 영향을 주면 DOM 순서와 렌더링 순서를 모두 검사한다.
