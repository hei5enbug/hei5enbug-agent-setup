# Google Docs 원본

> 영어 원본: [google-docs.md](google-docs.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

네이티브 Google Doc에 이 어댑터를 사용한다. 익명 URL 요청이 아니라 인증된 Google Drive 또는 Docs
커넥터로 접근한다.

## 안정적인 캡처

파일 ID와 사용할 수 있는 가장 강한 개정 식별자 또는 수정 시간을 기록한다.
요청된 모든 탭과 네이티브 구조를 읽는다. 네이티브 구조를 얻을 수 없으면 DOCX 또는 HTML로 내보내고
Google Drive 개정을 원본 표식으로 유지하면서 해당 어댑터를 적용한다.

## 콘텐츠 선택

제목, 문단, 목록, 표, 링크, 이미지, 각주, 북마크와 탭 순서를 보존한다.
독자가 대상에 접근할 수 있으면 지원되는 smart chip을 유용한 표시 텍스트와 안정적인 링크로 바꾼다.
사용자가 다른 표현을 요청하지 않으면 날짜와 사람 이름을 표시된 형태로 보존한다.

댓글, 제안, 해결된 스레드와 버전 기록은 페이지 본문이 아니라 검토 데이터다.
사용자가 요청할 때만 포함하고 제안을 조용히 승인하거나 거절하지 않는다.

## 에셋과 접근

가능하면 인증된 커넥터로 포함된 이미지를 내보내거나 내려받는다.
Google Drive 공유 권한이 Confluence에도 적용된다고 가정하지 않는다.
비공개 Drive 콘텐츠 링크는 대상 페이지 독자가 열 수 있는지 확인하거나 승인된 첨부 파일 또는 설명으로 바꾼다.

## 내용 일치 검사

요청한 탭 수, 제목, 문단, 목록 중첩, 표 크기, 링크, 이미지, 각주와 smart chip을 정규화 블록 목록과
비교한다. 게시 직전에 원본 개정을 다시 읽고 변경된 블록을 다시 만든다.
