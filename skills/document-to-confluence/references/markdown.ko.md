# Markdown 원본

> 영어 원본: [markdown.md](markdown.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

Markdown 파일, 조각과 프롬프트에 포함된 Markdown에 이 어댑터를 사용한다.

## 추출

ATX와 setext 제목 수준, 문단 경계, 목록 중첩, 블록 인용, fenced 코드 블록, 표, 링크, 이미지,
각주와 다이어그램 fence를 보존한다. frontmatter 키에 합의된 게시 목적이 있을 때만 문서 메타데이터로
취급한다. 빌드 설정이나 저장소 제어 값을 페이지 콘텐츠로 게시하지 않는다.

상대 에셋은 원본 파일 디렉터리를 기준으로 해석한다. 상대 링크는 의도한 대상을 판단하는 데만 사용한다.
게시 전에 저장소 상대 대상을 게시된 페이지 링크나 유용한 문구로 바꾼다. 절대 로컬 경로를 노출하지 않는다.

## 다이어그램과 포함된 HTML

fenced 다이어그램 원본을 공통 모델의 다이어그램 블록으로 유지한다.
게시 전에 `references/diagrams.md`를 적용한다.

raw HTML은 검사하기 전까지 지원되지 않는 Markdown 확장으로 취급한다.
의도적인 문서 콘텐츠라면 해당 블록에 `references/html.md`를 적용한다.

## 내용 일치 검사

원본이 선언된 지원 범위 안에 있을 때만 `scripts/text_parity.py`를 실행한다.
다이어그램 원본처럼 텍스트가 아닌 아티팩트로 의도적으로 바꾼 텍스트에는 `--drop`을 사용한다.
지원되지 않는 구조가 보고되면 일치한다고 보지 않고 직접 비교한다.

페이지를 저장하기 직전에 원본 파일 개정을 확인한다.
