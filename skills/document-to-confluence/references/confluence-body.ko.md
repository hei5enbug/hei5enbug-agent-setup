# Confluence HTML 본문 형식

> 영어 원본: [confluence-body.md](confluence-body.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

이 규칙은 전송한 본문을 Confluence HTML 변환기가 처리하는 방식을 설명한다.

## 확인 범위

**verified**로 표시한 항목은 Confluence Cloud REST API에 HTML 본문 표현을 전송하고 변환기가 저장한
내용을 다시 읽어 관찰했다. 당시 검사 날짜와 정확한 클라이언트를 기록하지 않았으므로 오래된 관찰일 수 있다.
처음으로 규칙과 다른 결과가 나오면 이 문서보다 페이지 결과를 신뢰하고 새 관찰의 날짜와 도구를 기록한다.

**convention**으로 표시한 항목은 안정적으로 작동했지만 실패 조건을 의도적으로 시험하지 않았다.
입증된 제약이 아니라 안전한 기본값으로 취급한다.

### 가정

다음 내용은 기록된 관찰 근거가 없으므로 사용할 때 확인한다.

- Confluence Data Center와 Server가 아래 규칙에서 Cloud처럼 동작한다. 실제로 시험하지 않았다.
- 연결된 모든 Confluence 도구가 여기서 사용하는 HTML 본문 표현을 받는다. storage 형식이나 ADF만 받는
  도구에는 이 문서가 설명하지 않는 변환 단계가 필요하다.
- `img`의 `width`, `height`, 표 셀의 블록 요소와 텍스트 이스케이프 규칙은 검증된 제약이 아니라 관례다.

## 본문 전체 교체

**Verified.** 부분 수정은 없으며 저장하면 본문 전체를 교체한다.

갱신은 항상 읽기, 수정, 전송 순서로 처리한다. 현재 본문을 읽지 않고 만든 본문을 보내면 포함하지 않은
콘텐츠를 삭제한다. 이전 저장에서 변환기가 만든 매크로 식별자 같은 값을 보존한다.

## 이미지

### 일반 img 요소 사용

**Verified.** 인라인 이미지를 배치하는 신뢰할 수 있는 방식이다.

```html
<p><img src="/wiki/download/attachments/PAGE_ID/FILENAME" alt="..." width="900" height="225"></p>
```

변환기는 이를 같은 너비 메타데이터를 가진 자체 figure 노드로 다시 작성한다. 그 노드를 직접 작성하지 않는다.

### 직접 작성한 media-single 거부

**Verified.** `data-type="media-single"`을 가진 `div`를 보내면 지원되지 않는 data-type 오류로 요청이 실패한다.
저장된 콘텐츠에서는 유효한 노드지만 HTML 변환기 입력으로는 허용되지 않는다.

### media-group은 카드로 렌더링

**Verified.** `data-type="media-group"`은 인라인 이미지가 아니라 첨부 파일 카드를 만든다.
요청은 성공하지만 문단이나 표 안 그림에는 잘못된 노드이며 오류가 표시되지 않고 페이지 모양만 잘못된다.

### 표 셀 안 이미지

**Verified.** 표 셀 안의 `img`는 정상적으로 변환되고 셀 안에 남는다.

```html
<td><p><img src="/wiki/download/attachments/PAGE_ID/before.jpg" alt="before" width="200" height="139"></p></td>
```

그림을 넣기 위해 표를 열 레이아웃으로 바꾸지 않는다. 필요하지 않은 이유로 문서 구조가 달라진다.

### 너비와 높이 지정

**Convention.** 파일에서 두 수치를 읽고 함께 비례 조정한다. 실제 비율과 다른 `img`는 늘어나 보인다.

크기를 줄일 수는 있지만 키우지 않는다. 파일 픽셀 너비보다 큰 표시 너비는 이미지를 흐리게 하므로
더 높은 해상도로 렌더링한다.

페이지 너비가 바뀌면 모든 표시 너비를 다시 검토한다. 좁은 페이지용 다이어그램은 넓은 페이지의 공간을
낭비하고 작은 이미지를 늘리면 읽기 어려워진다.

`scripts/image_size.py`가 계산한다. 반환된 `display_width`, `display_height`를 요소에 쓰고, 실제 파일 크기인
`width`, `height`는 비율 확인에만 사용한다. `clamped: true`면 요청 너비가 파일보다 커서 파일 너비로 줄었다.

### 식별자로 참조

**Verified.** 다운로드 URL 대신 식별자로 미디어 노드를 참조하려면 UUID인 미디어 파일 ID를 사용한다.
숫자 앞에 `att`가 붙은 첨부 파일 ID는 다른 값이다.

미디어 파일 ID 자리에 첨부 파일 ID를 전달해도 실패하지 않는다. Confluence가 식별자 문자열을 이름으로 한
빈 첨부 파일을 만들고 독자는 깨진 미리 보기를 본다. 삭제하려면 사용자 승인이 필요하다.

다운로드 URL은 이 문제를 피하므로 위 `img` 형식을 기본으로 사용한다.

## 목차

**Verified.** 제목이 바뀌어도 페이지가 유지되도록 직접 만든 목록 대신 내장 매크로를 사용한다.

```html
<div data-type="extension"
     data-extension-key="toc"
     data-extension-type="com.atlassian.confluence.macro.core"
     data-layout="default"
     data-parameters="{&quot;macroParams&quot;:{&quot;maxLevel&quot;:{&quot;value&quot;:&quot;3&quot;},&quot;minLevel&quot;:{&quot;value&quot;:&quot;2&quot;}}}"></div>
```

매크로 식별자를 지어내지 않는다. 새 매크로에는 생략하고 읽은 본문에 기존 값이 있으면 페이지가 해당
매크로 인스턴스를 추적하는 값이므로 그대로 돌려보낸다.

## 표

**Convention.** 모든 `td`, `th`의 콘텐츠를 블록 요소로 감싼다.

```html
<tr><td><p>text</p></td><td><p>more text</p></td></tr>
```

제목 셀은 `thead` 행에 둔다.

### 셀 간격

**Verified.** 셀 안의 문단 나눔과 줄바꿈은 다른 간격을 만든다. 한 표에서 두 형식을 섞으면 행 간격이
고르지 않다.

문서 안에서 한 형식을 일관되게 사용한다. 쌓인 값에는 줄바꿈, 별도 글에는 문단을 사용한다.
선택한 텍스트 간격과 관계없이 이미지는 자체 문단에 둔다.

### 표와 열 너비

**Verified.** 표의 `data-layout`과 각 셀의 `data-colwidth`는 변환 뒤에도 남고 다시 읽을 수 있다.

```html
<table data-layout="full-width">
  <thead><tr>
    <th data-colwidth="220"><p>Code</p></th>
    <th data-colwidth="1580"><p>Decision</p></th>
  </tr></thead>
  <tbody><tr>
    <td data-colwidth="220"><p>ABCDE</p></td>
    <td data-colwidth="1580"><p>...</p></td>
  </tr></tbody>
</table>
```

제목을 포함해 같은 열의 모든 셀에 같은 값을 준다.

**Verified.** 너비는 고정 픽셀이 아니라 비율로 동작한다. 표가 사용 가능한 너비를 채우고 지정한 비율로 나눈다.

두 속성 모두 기본값이 아니다. 표 레이아웃을 페이지 너비에 맞춘다. 각 열의 콘텐츠가 비슷하고 균등 분할이
적절하면 열 너비를 생략한다.

너비가 필요하면 짧은 값을 가진 열에는 필요한 공간만 남기고 줄바꿈되는 열에 나머지를 준다.
가장 긴 줄로 필요 너비를 추정하고 CJK 글리프가 라틴 문자보다 넓다는 점과 인라인 코드 여백을 반영한다.
이미지 열에는 이미지 표시 너비와 같은 명시적 최소 너비를 준다.

`scripts/column_widths.py`가 결정적인 추정치를 만든다. 콘텐츠 가중치는 레이아웃 보조일 뿐 시각적 증거가
아니므로 게시 전에 결과를 검토한다.

## 텍스트

**Convention.** 본문 텍스트의 큰따옴표와 작은따옴표 및 일반 예약 문자를 이스케이프한다.
인라인 코드는 `code` 요소에 둔다.

### 문단 구조

원본 문서의 문단을 보존한다. 사용자가 요청할 때만 문단 안에 줄바꿈을 추가한다.

요청된 줄바꿈은 문장 경계에만 둔다. 이미 한 줄에 맞는 문단은 그대로 둔다.
표시 너비에서 기준을 계산하며 본문에는 페이지 너비, 표 셀에는 열 너비를 사용한다.

## 페이지에 맞지 않는 원본 아티팩트

변환 중 다음 항목을 제거하거나 바꾼다. 원본 앱에서는 유효할 수 있지만 쓸 수 있는 게시 페이지를 만들지 못한다.

| 원본 형식 | 실패 이유 | 대체 방식 |
|---|---|---|
| 절대 로컬 경로 | 독자에게 의미가 없고 디렉터리 구조를 노출한다. | 경로 대신 대상을 설명한다. |
| 상대 원본 문서 링크 | 페이지 독자에게 연결되지 않는다. | 게시된 대상에 연결하거나 문장에 대상 이름을 쓴다. |
| 다이어그램 원본 또는 지원되지 않는 포함 객체 | 텍스트로 보이거나 사라진다. | 지원되는 매크로나 접근 가능한 이미지를 사용한다. |
| 원본 앱 컨트롤 또는 작성자 노트 | 독자 콘텐츠가 아니다. | 사용자가 검토 데이터에 포함하지 않으면 제거한다. |
| 반복 페이지 머리말, 꼬리말 또는 번호 | 페이지 읽기 흐름을 끊는다. | 원본 어댑터가 역할을 확인한 뒤 제거한다. |

## 저장 전 체크리스트

`scripts/validate_body.py`가 다음 목록의 기계적인 부분을 검사한다.

- 직접 작성한 `media-single`, `media-group` 컨테이너가 없다.
- 모든 `img`에 `width`, `height`가 있으며 원본 픽셀보다 크게 조정하지 않는다.
- 모든 표 셀의 콘텐츠가 블록 요소로 감싸져 있다.
- 표 레이아웃, 열 너비와 셀 간격이 한 가지 규칙을 따른다.
- 로컬 파일 시스템 경로나 해결되지 않은 원본 문서 링크가 없다.
- 참조하는 모든 첨부 파일이 페이지에 이미 있다.
- 본문 텍스트가 일치 검사기의 지원 범위에서 원본과 같거나 지원되지 않는 구조를 직접 비교했다.
- 버전 메시지가 변경 사항을 이름으로 밝힌다.
