# 문서를 Confluence로 변환

> 영어 원본: [SKILL.md](SKILL.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

Markdown, HTML, PDF, DOCX 또는 Google Docs 콘텐츠를 Confluence 페이지로 변환하고 이후 원본 개정 내용과
페이지를 동기화한다. 표, 링크, 이미지, 첨부 파일, 다이어그램, 페이지 구조 또는 텍스트 정확도를 포함해
Confluence 문서를 가져오기, 게시, 이전, 갱신 또는 복구할 때 사용한다.

읽을 수 있는 원본과 Confluence 쓰기 경로가 필요하다. 원본 추출에는 연결된 서비스, 로컬 변환기,
문서 파서, PDF 텍스트 추출 또는 OCR을 사용할 수 있다. 필요한 기능이 없으면 사용자가 수동으로 게시할 수
있는 정규화 콘텐츠, 본문과 첨부 파일 계획을 만든다. 다이어그램 렌더링에는 헤드리스 브라우저가 필요하다.
이미지 측정에는 Python 표준 라이브러리를 사용한다.

영어 `SKILL.md`와 영어 참조 파일만 실행 원본으로 사용한다. `SKILL.ko.md`와 다른 `.ko.md` 파일은
사람을 위한 비권위 번역본이므로 실행 중 불러오지 않는다.

지원하는 문서를 Confluence 페이지로 게시하면서 의미, 구조, 관계와 유용한 시각 콘텐츠를 보존한다.

원본 추출과 Confluence 게시를 분리한다. 원본 어댑터 하나를 선택하고 공통 문서 모델로 정규화한 뒤
하나의 게시 절차를 실행한다. 원본 마크업을 Confluence에 직접 복사하여 정규화를 건너뛰지 않는다.

## 권한과 자료

상위 Confluence 지침이 도구 선택, 자격 증명, 댓글과 파괴적 작업을 규정한다.
이 스킬은 형제 스킬을 읽거나 호출하지 않는다.

현재 원본과 콘텐츠에 필요한 참조만 읽는다.

| 참조 | 읽는 조건 |
|---|---|
| `references/markdown.md` | 원본이 Markdown 파일이거나 프롬프트에 포함된 Markdown 텍스트다. |
| `references/html.md` | 원본이 HTML 파일, 조각 또는 렌더링된 웹 문서다. |
| `references/pdf.md` | 원본이 텍스트 PDF, 레이아웃 PDF 또는 스캔 PDF다. |
| `references/docx.md` | 원본이 DOCX 파일이다. |
| `references/google-docs.md` | 원본이 네이티브 Google Doc이다. |
| `references/document-model.md` | 추출한 콘텐츠를 변환하기 전에 항상 읽는다. |
| `references/confluence-body.md` | Confluence 본문을 만들거나 복구하기 전에 항상 읽는다. |
| `references/attachments.md` | 문서에 이미지나 다른 첨부 파일이 있다. |
| `references/diagrams.md` | 문서에 다이어그램이나 다이어그램 원본이 있다. |

필수 참조가 없으면 누락된 경로를 알리고 영향을 받는 변환이나 쓰기 전에 멈춘다.
누락된 계약을 추측한 요약으로 대체하지 않는다.

## 기능 경로

방식을 선택하기 전에 사용할 수 있는 기능을 확인한다. 필요한 구조를 보존하는 기존 연결 도구나 로컬
도구를 우선 사용한다. 사용자 승인 없이 변환기를 설치하거나 외부 서비스에서 OCR을 실행하거나 원본
콘텐츠를 다른 서비스에 업로드하지 않는다.

| 기능 | 우선 경로 | 대체 경로 |
|---|---|---|
| Confluence 페이지 접근 | 상위 지침이 요구하는 도구 | 수동 게시용 정확한 본문과 첨부 파일 계획을 만든다. |
| Google Docs 접근 | 인증된 Google Drive 또는 Docs 커넥터 | 내보낸 DOCX, HTML 또는 PDF 파일을 요청한다. |
| DOCX 추출 | 구조를 인식하는 문서 변환기 또는 파서 | 사용할 수 있는 오피스 앱으로 내보낸 뒤 결과를 검사한다. |
| PDF 추출 | 텍스트·레이아웃 추출기, 이미지 전용 페이지에는 OCR | 불확실한 영역을 옮기고 사용자 확인 대상으로 표시한다. |
| HTML 추출 | 신뢰하지 않는 스크립트를 실행하지 않는 DOM 파서 | 보이는 정적 콘텐츠를 사용하고 렌더링이 필요한 콘텐츠를 알린다. |
| 다이어그램 렌더링 | `scripts/render_diagrams.mjs` | 원본 아티팩트를 보존하고 렌더링이 남았다고 알린다. |
| 이미지 측정 | `scripts/image_size.py` | 확인된 픽셀 크기를 사용자에게 요청한다. |
| 본문 검증 | `scripts/validate_body.py` | `references/confluence-body.md`의 체크리스트를 적용한다. |
| Markdown 텍스트 일치 | 지원 범위에는 `scripts/text_parity.py` | 원본과 정규화 블록을 직접 비교한다. |
| 다른 원본의 일치 | 형식별 검사와 블록 목록 | 추출 모델과 원본을 나란히 비교한다. |
| 열 너비 | `scripts/column_widths.py` | 가장 긴 표시 값을 기준으로 추정하고 결과를 검사한다. |

원본, 요구사항과 사용 가능한 기능이 바뀌지 않는 동안 선택한 방식을 유지한다.
그중 하나가 바뀌면 다시 평가한다.

## 실행 설정

사용자에게 질문하기 전에 요청과 사용 가능한 근거에서 각 값을 결정한다.
누락된 선택이 게시 결과를 실질적으로 바꿀 때만 질문한다.

| 값 | 필요한 결정 |
|---|---|
| 원본 | 정확한 파일, URL, 연결 문서 또는 프롬프트 콘텐츠와 형식 |
| 원본 범위 | 문서 전체, 선택한 페이지, 이름이 있는 섹션 또는 선택한 탭 |
| 대상 | 기존 페이지 ID 또는 새 페이지의 스페이스와 상위 페이지 |
| 갱신 방식 | 원본으로 교체, 선택한 섹션 병합 또는 현재 페이지 복구 |
| 포함할 검토 데이터 | 댓글, 변경 추적, 주석, 발표자 노트와 숨긴 콘텐츠 처리 |
| 준비 디렉터리 | 쓰기 가능하고 Git이 무시하는 저장소 경로 또는 업로드 도구가 허용하는 임시 디렉터리 |
| 레이아웃 | 페이지 너비, 표 레이아웃, 열 너비와 이미지 표시 너비 |
| 탐색 | 페이지 제목과 목차 깊이 |
| 언어 | OCR, 글꼴, 문장 경계와 텍스트 비교에 사용할 원본 언어 |

첫 외부 쓰기 전에 대상을 확인한다. 페이지 전체를 교체하면 원본에 대응하지 않는 콘텐츠가 사라질 수 있는
갱신에서는 요청한 갱신 방식을 확인한다.

## 작업 순서

### 1. Confluence 정책 적용

Confluence 도구를 선택하거나 호출하기 전에 상위 Confluence 지침을 따른다.
쓰기 전에 명령이나 도구 계약을 확인한다. 결과를 바꾸는 기능 대체 경로를 기록한다.

### 2. 안정적인 원본 개정 캡처

선택한 형식 어댑터로 원본을 읽고 사용할 수 있는 가장 강한 개정 표식을 기록한다.

- 로컬 파일 경로, 크기와 수정 시간 또는 콘텐츠 해시
- Google Drive 파일 ID와 개정 또는 수정 시간
- 접근이 승인된 HTML의 URL과 조회 시간
- PDF의 페이지 범위와 추출 방식

기존 페이지를 갱신할 때는 현재 본문 전체와 버전을 읽는다. 저장은 본문을 교체하므로 요청 범위 밖의
콘텐츠와 기존 매크로 식별자를 보존한다.

### 3. 원본 구조 추출

선택한 원본 참조를 사용한다. 표시 세부 사항보다 의미 구조를 먼저 캡처한다.

- 제목과 각 수준
- 문단, 목록, 인용, 코드와 콜아웃
- 표, 병합 셀, 캡션과 각주
- 링크와 대상
- 이미지, 다이어그램, 첨부 파일과 대체 텍스트
- 블록의 순서, 그룹과 관계

읽을 수 없는 텍스트나 누락된 구조를 추론하지 않는다. 불확실성을 영향을 받는 블록에 연결하고
게시 전에 결과에 영향을 주는 불확실성을 해결한다.

### 4. 문서 정규화

`references/document-model.md`를 읽고 안정적인 원본 위치를 가진 원본 중립 블록 목록을 만든다.
단어, 수치, 계층, 순서, 표 관계, 링크 의도, 캡션과 대체 텍스트를 보존한다.

원본 어댑터가 문서 콘텐츠가 아니라고 확인한 경우에만 원본 앱의 장식, 반복 머리말·꼬리말과
작성 전용 컨트롤을 제거한다. 의도적으로 제외한 항목을 기록한다.

### 5. Confluence 본문 생성

`references/confluence-body.md`를 읽고 정규화 블록을 지원되는 Confluence 구조에 매핑한다.
사용자가 편집을 요청하지 않았다면 문구를 유지한다. 원본 의미가 아니라 컨테이너와 지원되지 않는
표현만 바꾼다.

탐색에 도움이 되면 네이티브 목차 매크로를 사용한다. 원본에 기록할 만한 예외가 필요하지 않다면
문서 전체에 하나의 표 간격과 너비 규칙을 적용한다. 로컬 파일 시스템 경로를 제거하고 해결되지 않은
상대 링크를 유용한 페이지 문구나 유효한 게시 대상으로 바꾼다.

### 6. 다이어그램과 첨부 파일 준비

다이어그램이 있으면 `references/diagrams.md`를 읽는다. 작동하는 Confluence 매크로를 사용할 수 있고
사용자가 요청한 경우가 아니면 다이어그램 원본을 이미지로 렌더링한다. 업로드 전에 모든 이미지의
겹침, 잘림, 빠진 글리프, 잘못된 연결선과 불필요한 여백을 검사한다.

첨부 파일이 있으면 `references/attachments.md`를 읽는다. 각 파일을 참조하기 전에 업로드한다.
`scripts/image_size.py`로 래스터 이미지를 측정하고 가로세로비를 보존한다. 첨부 파일 ID, 미디어 ID,
크기 또는 파일 이름을 지어내지 않는다.

### 7. 내용과 본문 구조 검증

`scripts/validate_body.py`를 실행하고 선언된 범위의 모든 지적을 고친다.

스크립트가 지원하는 Markdown 범위에는 `scripts/text_parity.py`를 실행한다. 다른 모든 원본은
정규화 블록 목록을 원본과 생성한 본문에 비교한다. 제목, 문단, 목록, 표 행과 열, 링크, 이미지,
다이어그램, 각주와 의도적인 제외 항목의 정확한 텍스트와 개수를 확인한다. 도구가 비교하지 못하는
구조는 직접 검사한다.

원본 개정 표식이 바뀌면 원본을 다시 읽고 영향을 받는 블록을 다시 만든 뒤 검증을 반복한다.

### 8. 동시 수정 방지 후 저장

저장 직전에 대상 페이지 버전을 다시 읽는다. 앞서 캡처한 버전과 다르면 멈추고 두 버전을 알린다.
다른 편집자의 변경을 덮어쓰지 않는다.

원본 개정이 바뀌지 않았는지 확인한다. 원본과 변경 사항을 이름으로 밝힌 버전 메시지와 본문 전체를
전송한다. 요청이 너무 크면 완전한 블록 단위로 구성한 뒤 쓰기 전에 결합한다.

### 9. 저장 결과 확인

저장된 페이지를 렌더링 또는 저장 형식으로 읽는다. 제목, 계층, 텍스트, 표, 링크, 이미지, 첨부 파일,
매크로와 버전을 검증한 본문과 비교한다. 호스트가 표시할 수 있으면 시각 레이아웃을 검사한다.
사용한 기능 대체 경로와 사용자가 더 확인해야 하는 항목을 알린다.

### 10. 승인 후 정리

사용하지 않는 첨부 파일이나 임시 외부 아티팩트와 제거 이유를 나열한다.
사용자가 명시적으로 승인한 뒤에만 첨부 파일, 댓글 또는 외부 아티팩트를 삭제한다.

## 갱신 계약

캡처한 원본 개정과 정규화 블록 목록을 갱신 기준으로 사용한다. 다시 게시할 때는 다음 순서를 따른다.

1. 추가, 변경, 이동 또는 삭제된 원본 블록을 찾는다.
2. 원본에서 온 페이지 콘텐츠와 Confluence에만 있는 콘텐츠를 구분한다.
3. Confluence 전용 콘텐츠를 몰래 삭제하지 않고 요청한 갱신 방식을 적용한다.
4. 의미 콘텐츠가 유지되면 안정적인 첨부 파일 이름과 매크로 식별자를 보존한다.
5. 원본 형식이나 내보내기 도구가 바뀌면 블록 경계가 달라질 수 있으므로 추출을 다시 실행한다.

## 모든 원본의 규칙

- 사실 내용, 순서, 계층, 부정, 불확실성, 단위와 링크 의도를 보존한다.
- Confluence가 지원하면 원본 구조를 보존한다. 의도적인 구조 하향 변환을 모두 기록한다.
- OCR 텍스트, 잘못된 표 또는 모호한 읽기 순서를 확인된 콘텐츠로 게시하지 않는다.
- 로컬 경로, 자격 증명, 숨긴 문서 데이터 또는 지원되지 않는 비공개 링크를 노출하지 않는다.
- 원본 구조를 지원하지 않는 검증기로 원본 일치를 확인했다고 주장하지 않는다.
- 첫 쓰기 전에 대상을 확인하고 모든 쓰기 뒤에 저장된 페이지를 검증한다.
- 영구 삭제 전에 질문한다.

## 포함된 자료

| 경로 | 계약 |
|---|---|
| `scripts/image_size.py` | PNG, JPEG, GIF 크기를 읽는다. 지원되지 않거나 잘린 입력을 알리고 제한된 표시 크기를 계산한다. |
| `scripts/column_widths.py` | 정수 열 너비 비율을 만들고 불가능한 최소값이나 불완전한 이미지 제약을 거부한다. |
| `scripts/text_parity.py` | 선언된 Markdown 범위의 텍스트를 비교하고 지원되지 않는 구조를 알린다. |
| `scripts/validate_body.py` | 선언된 범위 안에서 기계적인 Confluence 본문 규칙을 검사한다. |
| `scripts/render_diagrams.mjs` | 로컬 HTML에서 유효하고 고유한 요소 ID를 캡처하며 항상 브라우저를 닫는다. |
| `assets/diagram-template.html` | 일관된 HTML·CSS 다이어그램을 위한 시작점을 제공한다. |

각 스크립트의 정확한 인터페이스는 `--help`로 확인한다.
