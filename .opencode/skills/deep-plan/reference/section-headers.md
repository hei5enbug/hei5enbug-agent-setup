# Section Header Mapping (English → Korean)

Use these Korean equivalents for all section headers in output plan documents.

| Template (English) | Output (Korean) |
|--------------------|-----------------|
| Task NNN: {Title} | 태스크 NNN: {제목} |
| Priority | 우선순위 |
| Size | 공수 |
| Problem | 문제 |
| Solution | 해결 방안 |
| Affected Files | 영향 파일 |
| Implementation Steps | 구현 단계 |
| Verification | 검증 |
| Related Tests | 관련 테스트 |
| Preconditions | 사전 조건 |
| Postconditions | 사후 조건 |
| Dependencies | 의존성 |
| {Plan Name} | {플랜 이름} |
| Overview | 개요 |
| Decision Log | 결정 로그 |
| Tasks | 태스크 |
| Execution Instructions | 실행 지침 |
| Parallel Execution Model | 병렬 실행 모델 |
| Execution Procedure | 실행 절차 |
| Rules | 규칙 |
