# 독립 모델 검증

> 영어 원본: [independent-model-validation.md](independent-model-validation.md)
>
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트는 실행 중 이 문서를 읽거나 사용하지 않는다.

영문 `independent-model-validation.md`를 구현 계획, 기술 설계 문서, RFC와 완료된 구현 변경의 독립 검증에 사용하는 단일 기준으로 삼는다.

## 확인 게이트

독립 검증은 현재 산출물에 대해 사용자가 승인했을 때만 실행한다. 요청한 계획·설계·RFC는 초안을 완성한 뒤 검토를 제안한다.
구현은 변경과 검사를 마친 뒤, 동작·공개 계약·보안·동시성·마이그레이션 또는 여러 구성요소가 실질적으로 바뀌면 한 번 추천한다.
일상적인 작은 수정은 사용자가 요청하지 않으면 별도 검토를 생략한다.

기존 승인이 없는 산출물마다 아래 검토 모델과 사고 강도를 밝힌 짧은 질문 하나로 묻고 답을 기다린다.
해당 결과에 대한 명시적 승인은 재사용한다. 일반적인 작업 방식에 동의한 것은 검토자 호출 승인이 아니다.
답과 무관하게 할 수 있는 작업은 먼저 모두 마친다. 필요한 검토자를 사용할 수 없다는 사실을 이미 알면 제한을 보고하고 호출 없이 마친다.

사용자가 거절하거나 세션이 답을 받을 수 없으면 검토를 건너뛰고 마친다. 산출물은 작성한 그대로 두고, 건너뛴 검토를
산출물 안에 기록하지 않으며, 독립 검증을 실행하지 않았다고 답변에서 알린다. 같은 초안에 대해 다시 묻지 않는다.

## 검토자 선택

위 확인 게이트를 사용자가 승인한 뒤 완성된 초안을 다른 모델 계열의 검토자 1명에게 읽기 전용 세션으로 정확히 한 번
전달한다. 검토자에게 확정한 의도, 관련된 신뢰할 수 있는 근거, 완성된 초안을 제공한다. 검토자는 지적만 반환하며,
최종 결정은 작성 세션에서 내린다.

다음 모델 매핑을 사용한다.

| 작성 모델 계열 | 검토 모델 | 추론 강도 |
|---|---|---|
| GPT | `claude-fable-5-1` | `xhigh` |
| Claude | `gpt-6.1-sol` | `xhigh` |

고정 모델 ID를 그대로 사용하고 기록한다. 새 릴리스를 찾거나 제공자 별칭을 따르지 않으며, 작성 모델과 같은 계열, 다른 모델
등급, 더 낮은 추론 강도로 대체하지 않는다. 검토자는 초안, 저장소 또는 외부 상태를 수정하면 안 된다.

메인 세션의 모델과 사고 강도는 유지한다. 별도 호스트 실행기에 검토자의 모델과 사고 강도를 명시적으로 전달하고,
읽기 전용 도구나 샌드박스를 적용한다. 검토 완료로 인정하기 전에 호스트 기록에서 실제 모델과 사고 강도를 확인한다.
알리지 않은 모델 대체나 사고 강도 상한이 적용된 호출은 완료된 검토가 아니다. 검토를 실행하려고 추가 과금을 켜거나 인증을 바꾸지 않는다.

구현 검토에는 대화 기록 대신 합의한 범위, 전체 변경 diff, 관련 원본 경로, 수용 조건과 검사 결과를 전달한다.
필요한 미추적 파일도 포함한다. 추적 파일만의 diff는 구현을 빠뜨릴 수 있다. 심각도와 근거가 있는 간결한 지적을 반환한다.

## 검토 항목

모든 결과물에서 다음 항목에 대해 근거가 있는 지적만 보고한다.

- 누락된 요구사항 또는 인수 조건
- 모순과 실질적으로 모호한 표현
- 근거 없는 가정
- 불필요한 추상화, 추측성 확장성, 관련 없는 리팩터링 또는 과도한 의존성

구현 계획에서는 다음 항목도 확인한다.

- 잘못된 의존성 또는 실행 순서
- 실행하거나 검증할 수 없는 단계
- 불필요한 실행 단위 또는 안전하지 않은 병렬 실행 판단

완료된 구현에서는 다음 항목도 확인한다.

- 정확성, 회귀, 권한 경계와 실패 처리
- 빠진 수용 검사 또는 근거 없는 검증 성공 주장
- 통합 충돌, 안전하지 않은 동시 실행과 불완전한 메인 대체 처리

기술 설계 문서나 RFC에서는 다음 항목도 확인한다.

- 목표 결정을 뒷받침하지 않는 현재 상태 설명
- 누락되거나 부정확한 계약, 제약, 대안 또는 주요 트레이드오프
- 요청하지 않은 구현 단계, 낮은 수준의 세부사항 또는 확장 지점

## 실행 범위

이 과정은 토론이 아니라 검증 1회다. 검토자에게 답변 수정을 요청하거나 다른 검토자를 호출하거나 최종 확정 뒤 검증을
반복하지 않는다. 검토가 실패하거나 검토자를 사용할 수 없어도 두 번째 모델을 호출하지 않는다. 게이트를 거절한 경우에도
대체 독립 검토를 허용하지 않는다. 작성자의 일상적인 점검과 필수 검사는 계속하되 독립 검증이라고 부르지 않는다.

필요한 모델, 추론 강도, 읽기 전용 실행 또는 모델 실행기를 사용할 수 없다면 다른 설정으로 대체하거나 작성자 점검을 독립 검토로 제시하지 않는다.
검토자 없이 할 수 있는 작업은 마치고 독립 검증을 수행하지 못한 사실과 사유를 알린다.

## 확정

작성 세션은 모든 지적을 확정한 범위와 신뢰할 수 있는 근거에 대조하고, 근거가 있는 수정만 한 번 반영하며, 근거 없는
범위 확장은 거부한다. 수정한 뒤 다른 모델 검토를 실행하지 않는다.

실제로 사용한 검토 모델, 추론 강도, 읽기 전용 검증을 한 번 실행한 사실, 미해결 지적을 알린다. 검증을 실행하지
못했다면 사용할 수 없었던 조건과 사유를 대신 밝힌다. 사용자가 게이트를 거절했다면 독립 검증을 실행하지 않았다는
사실만 알린다. 이 결과는 모두 답변에 적고 산출물에는 적지 않는다.
