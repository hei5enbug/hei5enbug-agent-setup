# 독립 모델 검증

> 영어 원본: [independent-model-validation.md](independent-model-validation.md)
>
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트는 실행 중 이 문서를 읽거나 사용하지 않는다.

영문 `independent-model-validation.md`를 구현 계획, 기술 설계 문서, RFC의 독립 검증에 사용하는 단일 기준으로 삼는다.

## 검토자 선택

작성자가 초안을 완성한 뒤 다른 모델 계열의 검토자 1명에게 읽기 전용 세션으로 정확히 한 번 전달한다. 검토자에게
확정한 의도, 관련된 신뢰할 수 있는 근거, 완성된 초안을 제공한다. 검토자는 지적만 반환하며, 최종 결정은 작성 세션에서
내린다.

다음 모델 매핑을 사용한다.

| 작성 모델 계열 | 검토 모델 | 추론 강도 |
|---|---|---|
| GPT | 사용 가능한 최신 Claude Fable | `high` |
| Claude | 사용 가능한 최신 GPT Sol | `xhigh` |

실행 시점에 호스트의 현재 Fable 또는 Sol 선택자를 확인하고 실제 모델을 기록한다. 작성 모델과 같은 계열, 다른 모델
등급, 더 낮은 추론 강도로 대체하지 않는다. 검토자는 초안, 저장소 또는 외부 상태를 수정하면 안 된다.

## 검토 항목

모든 결과물에서 다음 항목에 대해 근거가 있는 지적만 보고한다.

- 누락된 요구사항 또는 인수 조건
- 모순과 실질적으로 모호한 표현
- 근거 없는 가정
- 불필요한 추상화, 추측성 확장성, 관련 없는 리팩터링 또는 과도한 의존성

구현 계획에서는 다음 항목도 확인한다.

- 잘못된 의존성 또는 실행 순서
- 실행하거나 검증할 수 없는 단계
- 불필요한 실행 단위 또는 안전하지 않은 병렬 실행 판단

기술 설계 문서나 RFC에서는 다음 항목도 확인한다.

- 목표 결정을 뒷받침하지 않는 현재 상태 설명
- 누락되거나 부정확한 계약, 제약, 대안 또는 주요 트레이드오프
- 요청하지 않은 구현 단계, 낮은 수준의 세부사항 또는 확장 지점

## 실행 범위

이 과정은 토론이 아니라 검증 1회다. 검토자에게 답변 수정을 요청하거나 다른 검토자를 호출하거나 최종 확정 뒤 검증을
반복하지 않는다. 검토가 실패하거나 검토자를 사용할 수 없어도 두 번째 모델을 호출하지 않는다.

필요한 모델, 추론 강도, 읽기 전용 실행 또는 모델 실행기를 사용할 수 없다면 다른 설정이나 자체 검토로 대체하지 않는다.
검토자 없이 할 수 있는 작업은 마치고 독립 검증을 수행하지 못한 사실과 사유를 알린다.

## 확정

작성 세션은 모든 지적을 확정한 범위와 신뢰할 수 있는 근거에 대조하고, 근거가 있는 수정만 한 번 반영하며, 근거 없는
범위 확장은 거부한다. 수정한 뒤 다른 모델 검토를 실행하지 않는다.

실제로 사용한 검토 모델, 추론 강도, 읽기 전용 검증을 한 번 실행한 사실, 미해결 지적을 알린다. 검증을 실행하지
못했다면 사용할 수 없었던 조건과 사유를 대신 밝힌다.
