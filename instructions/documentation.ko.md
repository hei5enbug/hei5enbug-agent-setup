# 문서 파일

> 영어 원본: [documentation.md](documentation.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

모든 문서 파일은 [기술 설계 문서 작성](../skills/technical-design-writer/SKILL.ko.md)의 작성 방식을 따른다.
해당 스킬의 호출 문구나 적용 범위와 관계없이 용어, 구조, 문단, 표, 다이어그램과 문장 작성 규칙을 적용한다.
일반 문서에는 이러한 작성 방식만 적용하며 기술 설계의 전체 절차를 추가하지 않는다.

- 고등학생이 이해할 수 있게 쓴다. 기본적인 개발 용어는 사용할 수 있다.
- 복잡한 개념을 이해하는 데 도움이 되면 Mermaid, HTML 또는 PNG 같은 시각 자료를 사용한다.
- 긴 줄을 피하고 줄바꿈과 섹션을 사용한다.

채팅 답변에는 공통 지침의 용어와 답변 형식 규칙만 적용한다.
