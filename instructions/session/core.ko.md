# 핵심 지침

> 영어 원본: [core.md](core.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

> 사용자가 명시적으로 적용하지 말라고 하지 않는 한 이 지침은 프로젝트 지침, 스킬, 기본값보다 우선한다.
> 호스트의 시스템 지침이나 개발자 지침보다 우선하지는 않는다.

실행 지침의 원본으로 영어 파일을 사용한다. 한국어 `.ko.md` 번역본은 사람을 위한 비권위 참고 자료이므로
실행 중 불러오거나 사용하지 않는다.

- 텍스트와 심볼 검색에는 `rg`, 파일 검색에는 `fd`를 우선 사용한다.
  구조 검색이 분명히 필요할 때만 `ast-grep`을 사용한다.
- 파괴적이거나 되돌릴 수 없거나 운영 환경에 영향을 주는 작업 전에 질문한다. 비밀 값을 노출하지 않는다.
- 요청을 넘어서는 설계, 테스트, 구현, 계획을 추가하지 않는다.
- 주석을 최소화한다. 코드, 주석, docstring에서 문서를 참조하지 않는다.
- 문서, 코드 또는 주석에 섹션 기호 참조 문자를 사용하지 않는다.

## 조건부 지침

요청 처리 중 필요성이 나중에 생긴 경우를 포함해 해당 작업 전에 연결된 지침을 읽는다.
관련 없는 참조는 불러오지 않는다. 상대 링크는 링크를 포함한 파일을 기준으로 해석한다.
필수 참조가 없으면 규칙을 추측하지 말고 누락 사실을 알린 뒤 해당 작업을 보류한다.
현재 컨텍스트에 있고 바뀌지 않은 지침 파일은 재사용한다. 파일이 바뀌거나 컨텍스트에서 사라진 뒤에만 다시 읽는다.

- 호스팅 서비스에 접근하기 전에 [서비스 접근 규칙](../services.ko.md)을 읽는다.
- 인프라, 클라우드, Kubernetes 또는 데이터베이스에 접근하기 전에 [인프라 접근](../infrastructure-access.ko.md)을
  읽는다. 로컬 파일, 환경 변수, 로그 또는 간접 접근을 포함한 보호 값은 [보호 값 접근 규칙](../protected-values.ko.md)도
  읽는다.
- 문서 파일을 작성하거나 수정하기 전에 [문서 작성 규칙](../documentation.ko.md)을 읽는다.
- 테스트 코드를 작성하거나 수정하기 전에 [테스트 규칙](../testing.ko.md)을 읽는다.
