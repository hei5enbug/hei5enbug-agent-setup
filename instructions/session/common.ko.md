# 공통 지침

> 영어 원본: [common.md](common.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

> 사용자가 명시적으로 적용하지 말라고 하지 않는 한 이 지침은 프로젝트 지침, 스킬, 기본값보다 우선한다.
> 호스트의 시스템 지침이나 개발자 지침보다 우선하지는 않는다.

실행 지침의 원본으로 영어 파일을 사용한다. 한국어 `.ko.md` 번역본은 사람을 위한 비권위 참고 자료이므로
실행 중 불러오거나 사용하지 않는다.

- 계획, 아키텍처, 장단점, 문제 정의, 복잡한 디버깅, 검토와 주요 결정은 메인 세션에서 처리한다.
  높은 수준의 추론을 위임하지 않는다.
- 텍스트와 심볼 검색에는 `rg`, 파일 검색에는 `fd`를 우선 사용한다.
  구조 검색이 분명히 필요할 때만 `ast-grep`을 사용한다.
- 대상이 알려진 심볼, 파일 경로, glob 또는 리터럴 문자열이면 메인 세션에서 직접 검색한다.
  조사 대상이 둘 이상이고 서로 파일을 공유하지 않으며 각각 여러 파일을 읽어야 할 때만 조사를 위임한다.
- 파괴적이거나 되돌릴 수 없거나 운영 환경에 영향을 주는 작업 전에 질문한다. 비밀 값을 노출하지 않는다.
- 주석을 최소화한다. 코드, 주석, docstring에서 문서를 참조하지 않는다.
- 문서, 코드 또는 주석에 섹션 기호 참조 문자를 사용하지 않는다.

## 조건부 지침

요청 처리 중 필요성이 나중에 생긴 경우를 포함해 해당 작업 전에 연결된 지침을 읽는다.
관련 없는 참조는 불러오지 않는다. 상대 링크는 링크를 포함한 파일을 기준으로 해석한다.
필수 참조가 없으면 규칙을 추측하지 말고 누락 사실을 알린 뒤 해당 작업을 보류한다.

- 호스팅 서비스에 접근하기 전에 [서비스 접근 규칙](../services.ko.md)을 읽는다.
- 로컬 파일, 환경 변수, 로그 또는 간접 접근을 포함한 Azure 또는 Kubernetes 접근 전에
  [보호 값 접근 규칙](../protected-values.ko.md)을 읽는다.
- 문서 파일을 작성하거나 수정하기 전에 [문서 작성 규칙](../documentation.ko.md)을 읽는다.

## 계획과 설계 작업

- 구현 계획은 실행자가 설계를 추가하지 않고 진행할 수 있어야 한다. 설계 문서는 목표 설계를 공유하며, 기존 문제는
  목표 설계를 설명하는 데 필요한 만큼만 다룬다. 요청 유형이 불분명하고 선택에 따라 결과가 실질적으로 달라지면
  사용자에게 확인한다.
- 사용자가 구현 계획, 설계 문서 또는 RFC를 명시적으로 요청하거나 스킬을 직접 호출했을 때만 관련 스킬을 실행한다.
  일반 구현, 진단, 코드 리뷰, 요약 또는 단순 언급만으로 실행하거나 다른 스킬을 연쇄 호출하지 않는다.
- `document-to-confluence`, `suggest-commit`, `technical-design-writer`는 스킬 설명이 사용자 의도와 일치하면 자동으로
  실행할 수 있다. 이 항목은 앞의 실행 조건에 대한 예외다.
- 구현 계획을 작성하거나 수정하기 전에 [구현 계획 규칙](../implementation-planning.ko.md)과
  [독립 모델 검증](../independent-model-validation.ko.md)을 읽는다.
- 설계 문서나 RFC를 작성하거나 수정하기 전에 [독립 모델 검증](../independent-model-validation.ko.md)을 읽는다.
  설계 문서 전용 절차와 템플릿은 설계 작성 스킬에서 관리한다.

## 답변

- 용어는 사용자 또는 프로젝트 용어집, 구현과 계약의 리터럴 이름, 공식 제품명이나 정립된 분야 용어,
  정립된 쉬운 표현, 가장 일반적인 기존 표현 순으로 선택한다. 한 의미에는 한 용어를 사용하고 한 용어에는
  한 의미만 부여한다. 낯선 용어와 유용한 약어는 한 번 정의한다. 정확한 용어를 더 쉽지만 다른 뜻의 용어로
  바꾸지 않으며 반복되는 용어의 일관성을 확인한다.
- 답변에 Mermaid나 렌더링되지 않는 다른 다이어그램 소스를 넣지 않는다.
  단순한 관계에는 표, 목록 또는 인라인 표기를 사용하고 공간 관계를 보여 주면 유용할 때는 ASCII 그림을 사용한다.
