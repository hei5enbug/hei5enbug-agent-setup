# 모델 평가

> 영어 원본: [model-evaluation.md](model-evaluation.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

추가 모델 시험과 벤치마크에 적용한다. 일반 구현, 단위 테스트, 필요한 빌드, 별도 계약을 따르는 독립 마무리
리뷰에는 적용하지 않는다. 현재 평가의 실행 권한은 재사용한다. 종료한 실험과 당시 예산은 새 실험의 실행 권한이
아니다.

시작 전에 판단할 질문, 확정한 사례·기준, 실행기 설정, 시험 예산, 중단 사유를 적는다. 경계 사례를 포함한 대표 사례
최대 3개와 묶음 전체 기한 15분을 기본값으로 한다. 쌍 비교는 각 방식을 1회씩 실행하므로 모든 호스트를 합쳐
최상위 시험 시작 최대 6회이며 재시도도 포함한다. 재개·호스트 전환·작업자가 같은 횟수와 기한을 공유하고 묵시적으로
초기화하지 않는다.

실제 CLI 호출, 자격 증명을 노출하지 않는 인증 가능 여부, 제공되는 사용량 한도, 픽스처 의존성, 출력 파싱을 확인한다.
승인된 작은 시험 1건을 품질 검사·사용량 기록까지 끝낸 후 확대한다. 이 시험도 예산에 포함한다. 측정한 시간으로
다음 묶음 전에 경과 시간과 남은 작업의 예상 범위를 알린다. 실제 경과 시간, 병렬 작업자 시간, 일부만 보고된 토큰을
구분한다. 달러 비용을 지어내거나 알 수 없는 사용량 한도가 충분하다고 가정하지 않는다.

추가 사례로 답할 수 있는 미해결 판단이 있고 명시적으로 승인된 더 큰 예산 안에 있을 때만 확대한다. 그렇지 않으면
결론 미확정으로 보고하고 필요할 때만 구체적인 확대안을 요청한다. 최대 예산은 목표가 아니다. 사례·호출·시간 상한,
사용자 중단, 필수 기능 미지원, 확인된 사용량 소진, 잘못된 계측 환경 중 먼저 발생한 조건에서 새 실행을 멈춘다.
유효한 부분 근거를 보존한다. 실행 환경 실패는 품질 실패도 통과도 아니다.

하위 프로세스 시험은 기존 기능으로 남은 묶음 시간 이하의 타임아웃을 설정하고 소유한 시험 프로세스만 정리한다.
안전한 중단을 지원하지 않으면 새 실행을 멈추고 대기 중인 호출과 시간 초과 가능성을 알린다. 지침은 엄격한 타임아웃을
강제할 수 없다. 근거가 바뀌거나 확대가 명시적으로 승인됐을 때만 중단한 묶음을 다시 열고, 이전 측정값은 지우지 않는다.
