# Documentation files

For any documentation file, follow the writing mechanics in
[technical-design-writer](../skills/technical-design-writer/SKILL.md).
Apply its terminology, structure, paragraph, table, diagram, and drafting-language rules regardless
of its trigger phrases or stated scope.
For ordinary documentation, apply these writing mechanics without adding the full technical design workflow.

- Write for high school students; basic development terms are allowed.
- Explain complex concepts with visuals such as Mermaid, HTML, or PNG when they aid understanding.
- Avoid long lines. Use line breaks and sections.

Chat replies use only the terminology and reply-format rules in the common instructions.
