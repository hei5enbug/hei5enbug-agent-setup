# 테스트 코드

> 영어 원본: [testing.md](testing.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

언어와 프레임워크에 관계없이 테스트를 작성하거나 수정할 때 다음 규칙을 적용한다.

- 모든 테스트를 given-when-then 구조로 작성한다. `given`은 상태와 fixture를 준비하고, `when`은 검증 대상 동작을
  정확히 하나만 수행하며, `then`에는 단언만 둔다. 세 단계를 눈에 보이게 구분한다. 프레임워크에 전용 구문이 있으면
  그것을 쓰고, 없으면 단계마다 표시 줄 하나를 둔다.
- `@DisplayName`, `describe`/`it` 제목, 실행기에 표시되는 docstring 같은 테스트 설명은 기대 동작을 서술하는
  자연스러운 한국어 문장으로 쓴다. 식별자, 메서드 이름, 리터럴 값은 그대로 둔다.
- JVM 프로젝트에서는 테스트 fixture를 Instancio로 만든다. 필요한 Instancio API가 불확실하면 추측하지 말고 공식
  문서를 확인한다. 프로젝트가 아직 Instancio에 의존하지 않으면 추가하기 전에 먼저 묻는다.
