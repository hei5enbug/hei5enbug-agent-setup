# Claude Code 계획 및 에이전트

> 영어 원본: [claude-agents.md](claude-agents.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

계획과 높은 수준의 추론은 메인 대화에서 처리한다.

[독립 모델 검증](independent-model-validation.ko.md)이 정한 검토자 호출은 아래 시점과 에이전트 선택 규칙의 예외다.

## 조사

- 내장 `Explore`, `Plan` 서브에이전트와 포괄형 `general-purpose`, `claude` 서브에이전트를 사용하지 않는다.
- 계획하는 동안 조사에만 `scout`를 사용한다.
- 대상이 알려진 심볼, 파일 경로, glob 또는 리터럴 문자열이면 메인 대화에서 `rg`, `fd` 또는
  `ast-grep`을 실행한다.
- 조사 대상이 둘 이상이고 서로 파일을 공유하지 않으며 각각 여러 파일을 읽어야 할 때만 `scout`를 실행한다.
- 각 `scout`에 질문 하나와 좁은 검색 범위 하나를 지정한다.
- 결과에 파일 경로, 코드 심볼과 구체적인 근거를 요구한다.
- 결과를 단서로 취급한다. 계획하거나 결정하기 전에 핵심 주장을 메인 대화에서 확인한다.
- `scout`가 설치되지 않았으면 메인 대화에서 조사한다.

## 구현

- 위 검토자 호출을 제외하면 메인 대화에서 계획을 확정한 뒤에만 `coder`, `tester`, `test-runner` 같은 작업
  서브에이전트를 사용한다.
- 범위가 명확한 코드 변경이나 테스트만 맡긴다.
- 파일을 공유하지 않고 빌드 경합이 없는 작업에만 최대 6개 서브에이전트를 동시에 사용한다.
  그 밖에는 순서대로 실행한다.
