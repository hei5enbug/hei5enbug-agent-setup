# 모델 라우팅

> 영어 원본: [model-routing.md](model-routing.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트는 실행 중 읽거나 사용하지 않는다.

이 파일은 공통 라우팅을 정의한다. 호스트 에이전트 규칙이 읽는 시점을 정하고 역할의 실행·검증 방법을
설명한다. 선택된 메인 모델이나 사고 강도를 바꾸지 않는다.

## 목적과 출력 위치에 따른 라우팅

위임할 작업의 목적과 결과를 저장할 위치를 함께 기준으로 삼는다.

| 작업 | 라우팅 |
|---|---|
| 메인이 맡는 작업 | [세션 소유권 규칙](session/common.ko.md)을 따른다. |
| 실제 저장소나 스킬을 수정하는 구현 | 호스트의 구현 실행 규칙과 고정된 구현 역할을 따른다. |
| 범위가 한정된 로컬 근거 수집 | 위임이 허용되고 유용할 때 호스트의 scout 역할을 쓴다. |
| 공개 자료의 읽기 전용 조사 | 공개 도구를 사용할 수 있고 고정 설정을 확인한 경우에만 호스트의 researcher 역할을 쓴다. 그렇지 않으면 메인 세션에서 계속한다. |
| 스킬의 조사, 시험 실행, 채점, 비교, 분석, 최적화 | 일반적인 스킬 작업자 라우팅보다 해당 스킬의 평가 계약을 먼저 적용한다. |
| 임시 시험 결과물 | 평가 작업 공간에 둔다. 이를 승인된 구현으로 간주하지 않는다. |

researcher는 주장, 공개 URL이나 파일 위치, 뒷받침하는 근거, 모순, 공백을 수집한다. 계획, 아키텍처, 승인
결정은 내리지 않는다. 기존 서비스 접근 규칙을 계속 적용한다.

## 역할 설정 유지

별도로 승인된 비교 결과가 한정된 범위의 변경을 정당화하지 않는 한 다음 운영 설정을 사용한다.

| 역할 | Codex | Claude Code |
|---|---|---|
| 로컬 scout | `gpt-6-luna`, `xhigh` | `claude-sonnet-5-5`, `medium` |
| 구현 worker | `gpt-6-luna`, `xhigh` | `claude-sonnet-5-5`, `high` |
| 공개 researcher | `gpt-6-luna`, `xhigh` | `claude-sonnet-5-5`, `medium` |
| Skill Builder 평가 참여자 | `gpt-6-luna`, `xhigh` | `claude-sonnet-5-5`, `high` |

결과를 신뢰하기 전에 호스트 기록과 관련된 비밀이 아닌 설정으로 역할의 실제 모델과 사고 강도를 확인한다.
요청한 값, 역할 이름, agent guard 승인만으로 실제 모델이 확인되지는 않는다. 설정이 없거나 충돌하거나
역할 요구보다 낮으면 허가된 메인 세션 대체 경로를 쓰고 제한을 한 번 보고한다. 위임을 가능하게 하려고
모델이나 사고 강도를 조용히 바꾸거나 사용자 설정을 변경하지 않는다.

공개 조사를 맡기기 전에 호스트에 필요한 공개 검색 및 가져오기 도구가 노출되는지, researcher 역할이 고정된
모델과 사고 강도로 실행되는지 확인한다. 둘 중 하나라도 충족하지 않으면 기존 서비스 접근 규칙에 따라 메인
세션에서 계속한다.

## 스킬 평가 설정 우선순위

Skill Builder가 대상 스킬을 평가하기 위해 시작한 평가 참여자는 Skill Builder의 필수 모델 및 사고 강도 표를
따른다. 대상 스킬의 메타데이터나 frontmatter는 평가자 계약을 덮어쓰지 않는다. 이 계약은 일반 호스트 스킬
작업자 라우팅보다 우선한다. 실제 설정이 Skill Builder 표와 일치할 때만 기본 역할을 실행한다. `high`
사고 강도가 필요한 평가자를 `medium` scout로 보내지 않는다. 이 불일치를 해결하려고 공유 scout의 운영 사고
강도를 높이지 않는다.

일치하는 기본 역할이 없으면 실제 모델과 사고 강도를 확인할 수 있을 때만 Skill Builder가 승인한 평가 runner를
쓴다. 그렇지 않으면 Skill Builder의 기능 미지원 경로를 따른다. runner 호출만으로 실제 설정이 확인된 것은
아니다.

일반적인 실행 방식 비교에서는 양쪽의 모델과 사고 강도를 고정한다. 구체적으로 승인된 모델 또는 사고 강도
비교에서는 임시 평가 작업 공간에서 미리 고정한 후보 설정 하나만 바꿀 수 있다. 이 비교로 운영 역할 설정을
변경하거나 시험 결과를 저장소에 반영해서는 안 된다. 충분한 근거가 없는 후보는 비활성 상태로 둔다. 시험한
작업 범위에서 변경을 정당화하는 결과 품질과 반복 실행 토큰의 비교 근거가 있을 때만 운영 설정을 바꾼다.

## 호스트와 모델 정체성 분리

메인 모델이 바뀌어도 실행 호스트는 그대로 유지된다. Claude Code에서 GPT를 선택해도 Claude Code의 도구,
권한, 에이전트 정의, 실행 규칙을 계속 적용한다. Claude worker의 고정 설정이나 호스트를 Codex로 바꾸지
않는다.

메인 모델이나 프로필을 바꾼 뒤, 또는 세션 재개 후 위임 작업을 호출하기 전에 실제 역할 설정과 관련 도구의
사용 가능성을 다시 확인한다. 각 역할의 고정 모델과 사고 강도를 유지한다. worker의 모델을 메인 모델과
같게 바꾸지 않는다.

선택적 독립 검토자는 실행 호스트가 아니라 결과물을 작성한 실제 모델 계열을 기준으로 고른다. 기존 검토
승인 및 모델 선택 규칙을 따른다. 두 계열이 모두 실질적으로 기여했으면 그 기여를 기록한다. 최종 작성자의
모델 계열이 승인된 검토자 한 명을 결정한다. 모든 기여자에 대한 독립성을 주장하거나 검토 호출을 추가하지
않는다.
