# Claude Code용 GPT 연결 구성요소

> 영어 원본: [claude-gpt.md](claude-gpt.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 실행 중 읽거나 사용하지 않는다.

## 현재 호환성

Claude Code `2.1.291`은 네이티브 텍스트·도구 스트림과 표시된 대화 기록을 제공하지만 Mod 도구 목록에는
입력 스키마가 없다. 재개 후 이전에 고정된 시스템 프롬프트에 접근할 수 있는지도 확인하지 못했다.
따라서 모듈은 프로필을 읽거나 네트워크를 호출하기 전에 GPT 메인 요청을 거부한다. `launch`도 선택기 설정을
만들기 전에 거부한다. Claude Code를 업데이트해도 이 어댑터가 자동으로 활성화되지 않는다.

고정 GPT ID `gpt-6.1-sol`, `gpt-6-luna`를 인식하지만 작동하는 선택기 항목으로 표시하지 않는다.
지원되는 어댑터, 세션에 연결된 프로필 선택, 기존 설정을 합친 세션 전용 선택기와 실환경 대화·재개·취소·권한·
할당량 검사는 여전히 필요하다. 일반 Claude 요청과 서브에이전트 요청은 그대로 전달한다.
차단된 경로를 Codex 실행 루프, 게이트웨이, 자동 대체 또는 사용자 설정 변경으로 바꾸지 않는다.

[검증 기록](model-routing-validation.ko.md)에 최신 무요청 호스트 검사, 개발 검사, 반복 토큰 측정과
남은 실환경 요구 사항을 정리했다.

## 명시적인 처리기 설정

처리기에는 Python 3.12 이상이 필요하다. 구독 신원 검증에는 PyJWT와 cryptography가 필요하다.
선택적 `claude-gpt` extra와 확정한 버전은 `pyproject.toml`, `uv.lock`에 있다. 소스 체크아웃에서
전용 실행 환경을 명시적으로 준비한다. 설치된 플러그인 캐시는 수정하지 않는다.

```bash
claude_gpt_runtime="${XDG_STATE_HOME:-$HOME/.local/state}/hei5enbug-agent-setup/claude-gpt-runtime"
UV_PROJECT_ENVIRONMENT="$claude_gpt_runtime" uv sync --extra claude-gpt --no-dev
"$claude_gpt_runtime/bin/python" scripts/claude_gpt.py launch
```

마지막 명령은 현재 인증·설정·세션을 바꾸지 않고 `unsupported_host`를 반환한다.
일반 시작과 요청에서는 의존성을 설치하거나 로그인하지 않는다. 새 실행 환경으로 누락된 호스트 입력을
해결할 수 없으므로 이 제약을 확인하는 데 인증은 필요 없다.

## 인증 명령

이 구성요소는 오프라인 검사를 마쳤다. 실환경 앱 승인과 계정 자격은 미검증이다.
모드를 명시적으로 선택한 뒤에만 인증한다. 기존 Codex 로그인은 플러그인 자격 증명이 아니다.

| `scripts/claude_gpt.py` 뒤에 붙일 명령 | 동작 |
|---|---|
| `auth subscription` | 새 루프백 콜백, PKCE, state, nonce로 공개 ChatGPT 앱 승인 절차를 열고 성공한 권한만 저장한다. 자격이 있으면 권장하는 모드다. |
| `auth subscription --profile <profile-id>` | 해당 프로필의 발급된 클라이언트 ID와 계정 매핑을 재사용하고 다른 subject를 거부한다. 로그아웃한 프로필도 저장된 토큰 없이 다시 인증할 수 있다. |
| `auth api-key` | API 사용량 과금 동의를 받은 뒤 터미널에서 키를 가려 입력받는다. |
| `auth api-key --from-env OPENAI_API_KEY` | 과금 동의를 받고 명시한 변수만 가져온다. 환경 변수의 존재만으로 API 과금을 선택하지 않는다. |
| `status [--profile <profile-id>]` | 자격 증명 없이 프로필 ID·모드·상태를 반환한다. 이 명시적 명령은 보호된 설정 디렉터리를 만들 수 있다. |
| `logout --profile <profile-id>` | 해당 프로필의 자격 증명·제공자 상태만 지우고 구독 취소를 시도한다. 앱·계정 매핑과 고정 호스트 ID는 보존한다. 원격 취소를 확인하지 못했으면 알린다. |

인증 명령은 설정이 성공한 뒤에만 처리기의 선택된 프로필을 갱신한다. 현재 지원하지 않는 호스트에서는
Claude 세션에 프로필을 연결하지 않는다. 향후 지원되는 실행기는 명시한 프로필을 세션 상태에 고정하고
재개할 때 보존해야 한다. 처리기의 전역 선택을 바꿔도 기존 대화의 과금 모드가 바뀌면 안 된다.

## 자격 증명과 요청 경계

프로필은 `~/.config/hei5enbug-agent-setup/claude-gpt/`에 저장한다. 디렉터리는 소유자만 접근하고,
자격 증명은 `0600`으로 원자적으로 쓴다. 안전하지 않은 소유권·심볼릭 링크·넓은 권한은 거부한다.
구독 로그인은 ID 토큰의 서명·발급자·대상·만료·nonce·subject와 승인된 직접 사용 범위를 검증한다.
갱신은 직렬화하고 회전된 자격 증명을 원자적으로 저장한다. Claude·Codex 자격 증명은 읽거나 바꾸지 않는다.

버전 1 요청은 표준 입력으로 전달하며 명시적인 세션·턴·단계 ID, 프로필 참조, 전체 모델 ID, 지원 사고 강도,
시스템·개발자 내용, 표시된 대화와 제공된 도구 스키마를 포함한다. 비밀값은 요청 프로토콜, 모델 프롬프트,
인수, 설정, 테스트 입력, 사용량 증빙에 넣지 않는다. 오류에는 정제한 코드만 노출한다.
인증·모델·제공자·과금 경로를 자동으로 바꾸거나 일부 출력 뒤 자동 재시도하지 않는다.

Responses 요청은 공개 `https://api.openai.com/v1/responses`, `store=false`, 스트리밍과 명시적 기록을
사용한다. 제공된 도구 중 지원하는 스키마만 변환한다. 서명된 Claude thinking은 제외하고 지원하지 않는
기록·스키마는 명시적으로 거부한다. 비공개 제공자 상태는 프로필·세션별로 분리하고 필요한 추론·도구 호출
상태만 보존한다. 별도 전체 대화록이나 서버 대화 ID는 만들지 않는다.

완료 전에 텍스트 조각이 나타날 수 있다. 실행할 도구 호출은 유효한 완료 응답과 처리기의 정상 종료를 확인할 때까지
보관한다. 알 수 없는 도구·잘못된 입력·과거와 현재의 중복 ID·잘린 스트림·할당량 오류·관측된 모델 및 사고 강도
불일치가 있으면 도구 호출을 받아들이지 않는다. 제공자가 알리지 않은 사고 강도는 미확인으로 기록한다.
Python은 도구를 실행하거나 권한을 승인하지 않는다. 네이티브 경로가 비활성화된 동안 실제 호스트 취소와
권한 검사 순서는 미검증이다.

## 등록과 되돌리기

Claude 매니페스트에 `config/claude-gpt-hooks.json`을 추가한다. 기본 `hooks/hooks.json`도 한 번만 읽힌다.
Codex 매니페스트와 기존 보안 가드는 유지한다. Mod는 `turn.step`만 처리하고 권한 승인 훅은 처리하지 않는다.
소스 체크아웃에서 추가 Claude 훅 참조를 지우면 모듈을 끌 수 있다. 기본 훅, researcher 등록, 사용자가 소유한
역할과 프로필은 보존한다. 현재 실행기는 세션 선택기나 기본 모델을 쓰지 않았다.

오프라인 테스트는 가짜 프로필과 서명된 합성 JWT로 인증·프로토콜 실패를 검사한다. 네이티브 Mod 테스트는
거부와 그대로 전달하는 동작을 확인하며 작동하는 GPT 백엔드를 증명하지 않는다. 비용 최적화나 실환경 호환성을
주장하기 전에 출력 품질과 제공자 토큰 증빙을 별도로 평가해야 한다.
