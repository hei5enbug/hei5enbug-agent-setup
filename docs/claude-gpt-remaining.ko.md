# Claude Code에 남은 GPT 연결 작업

> 영어 원본: [claude-gpt-compatibility.md](claude-gpt-remaining.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트는 실행 중 읽거나 사용하지 않는다.

[남은 작업](model-routing-remaining.ko.md)에 연결된 A10–A11 계약이다. 기존 구성요소와 해당 범위의 오프라인 검사는 재사용한다.
작동하는 네이티브 선택기·백엔드와 세션에 연결된 프로필은 아직 확보하지 못했다.
처리기 설정·보안 세부사항은 기존 [GPT 구성요소 안내](claude-gpt.ko.md)를 따른다.
모델·프로필 변경과 세션 재개 뒤에는 기존 [공유 라우팅 계약](../instructions/model-routing.ko.md)을 적용한다.

2026-10-07 무요청 재검사에서도 `2.1.291`의 차단 조건이 유지됨을 확인했다.
[검증 기록](model-routing-validation.ko.md)에 정확한 선언과 검사 결과를 보존했다.

## 차단된 호스트 선행 조건

확인한 Claude Code `2.1.291`은 `turn.step`의 text·tool·input·stop 형식과
`$.session.messages({ as: "api" })`의 정규화된 표시 기록을 제공한다. `ToolInfo`, `ToolDescribeInput`에는
입력 스키마가 없다. `$.prompt.compose()`만으로 재개 후 과거에 고정한 시스템 내용에 접근한다고 볼 수 없다.
실제 도구 권한 순서, 백그라운드 요청과 할당량 독립성도 미검증이다.

어댑터와 `launch`는 프로필·네트워크·추론 접근 전에 거부한다. 필요한 전체 입력을 지원하고 검증할 때까지
거부를 유지한다. 호스트 또는 인터페이스 근거가 바뀌지 않으면 같은 기능 확인을 반복하지 않는다.
근거가 바뀌면 메인이 설치 타입과 임시 요청 없는 입력으로 5분 이하의 읽기 전용 확인을 한 번 수행할 수 있다.
로그인·설치·모델 기능 요청은 하지 않는다.

정확한 프롬프트·기록·도구 스키마 접근, 네이티브 스트림·결과 타입, `next.signal`과 범위가 제한된
`$.process.spawn`의 취소, 훅 순서와 관리 설정 제한을 기록한다. 필요한 접근이 없으면 해당 경로를 차단한다.
이름이나 TypeScript 입력 선언에서 스키마를 추정하거나, 필수 시스템 내용을 근사하거나, Codex 루프로 바꾸거나,
제공자 데몬·오케스트레이터·범용 게이트웨이를 추가하지 않는다.

## 네이티브 연결 완성

호스트 선행 조건을 수락한 뒤에만 메인이 어댑터 계약을 고정하고 이 범위를 통합한다.
영향 경로는 `hooks/claude-gpt/register.js`, `protocol.js`, 해당 네이티브 테스트, `scripts/claude_gpt.py`,
`tests/test_claude_gpt.py`, GPT·루트 문서와 한국어 미러다. 검증된 호스트 타입에 필요할 때만 Claude 모듈 등록을
바꾼다. 기본 훅·보안 가드와 Codex 격리를 보존한다.

| 남은 동작 | 필수 계약 |
|---|---|
| 선택기·실행기 | 기존 Claude 항목·권한 플래그·관리 제한을 유지하는 임시 병합 `--settings`로 `launch`를 구현한다. 기존 `/model`에서 고정 `gpt-6.1-sol`, `gpt-6-luna`가 실제 백엔드로 연결되어야 한다. 기본값·사용자·프로젝트 설정은 쓰지 않는다. 미지원 ID·사고 강도·관리 제한은 명시적으로 실패한다. |
| 세션·프로필 | 명시적으로 선택한 불투명 프로필 ID를 Claude 세션에 연결하고 재개 때 보존하며 명시적으로만 바꾼다. 처리기의 전역 선택으로 기존 세션의 과금을 바꾸지 않는다. 인증은 구독 또는 API 키 사용량 과금을 제공하고 활성 자격 증명을 추정하지 않는다. |
| 네이티브 변환 | 세션·턴·단계 ID, 고정 모델, 지원 사고 강도, 프로필 참조, 전체 시스템·개발자 내용, 표시 기록과 실제 도구 스키마를 버전 1 요청으로 표준 입력에 전달한다. 실제 스키마·기록을 변환·검사하며 필수 제약을 버리거나 문맥을 지어내지 않는다. |
| 스트리밍·도구 | 네이티브 텍스트를 스트리밍하며 유효한 제공자 완료와 처리기의 정상 종료까지 실행할 도구 호출을 보관한다. 호출·결과 ID와 필요한 비공개 제공자 상태를 보존한다. Claude Code가 일반 승인·거부 훅으로 실행하고 Python은 실행하지 않는다. 잘못되거나 중복·미확인·잘린·불일치 호출은 거부한다. |
| 재개·취소·실패 | 호스트 기록이 정본이다. 별도 전체 대화록, 서명된 Claude thinking, 호환되지 않는 제공자 캐시 또는 서버 대화 ID로 대체하지 않는다. 검증된 호스트 계약으로 처리기·요청을 취소하고 확정 문맥을 보존하며 실패를 한 번 알린다. 과거 쓰기 재실행과 일부 출력 뒤 재시도는 금지한다. |
| 할당량·호스트 정체성 | 시작·백그라운드·압축을 포함해 GPT 추론에 Claude 모델 요청이 필요하지 않아야 한다. Claude·서브에이전트 요청은 그대로 전달한다. 메인 모델을 바꿔도 공유 계약의 호스트 권한·실제 역할 고정값·메인 대체·작성 계열 검토 규칙을 유지한다. |
| 자격 증명·의존성 | 보호된 처리기 프로필과 선택적 잠금 JWT·crypto 환경을 재사용한다. Codex·Claude 자격 증명은 읽거나 복사하지 않는다. 일반 시작·요청의 로그인·설치, 과금·모델·인증 자동 대체, 모델에 보이는 비밀값과 권한 훅 우회는 금지한다. |

네이티브 Mod와 가짜 프로필 처리기 테스트로 새 변환·선택기 병합·명시적 세션 연결·재개·취소·실패 경계를 검사한다.
바뀌지 않은 검사는 재사용하고 영향받은 근거만 무효화한다. 오프라인 성공과 실제 백엔드·사고 강도·권한·계정 자격의
관측은 구별한다.

## 필수 실환경 근거

두 수락 배치는 모두 닫혔다. 2026-10-07 추가 배치도 모델 시작 6회를 전부 사용했다.
필요한 최소 요청 목록을 고정하고 구체적인 새 모델 검증 승인을 받은 뒤 실행한다.
실제 프로필 로그인·인증 변경은 명시적인 승인이 필요하다. 두 번째 모드의 표를 채우려고 API 키를 요청하지 않는다.
충분한 관측 모드를 재사용하고 두 모드의 오프라인 검사는 유지하며, 별도 실환경 모드는 고유한 미해결 동작이 있을 때만
검증한다. 공유 한도와 중단 조건은 [남은 작업](model-routing-remaining.ko.md)에 있다.

| 검사 | 필요한 관측 |
|---|---|
| 백엔드·인증 | 실제 고정 GPT 백엔드, 지원 사고 강도 근거, 명시적인 선택 모드와 기존 Claude 선택기 항목 유지. 알리지 않은 사고 강도·계정 제한은 미확인으로 기록. 자동 사용량 과금 금지 |
| 대화·도구 기록 | 모델 전환·재개에서 합성 사실과 앞선 도구 결과 유지. 일반 호스트 도구·권한으로 범위를 정한 임시 코드 수정 한 번 성공. 재시작에서 호출 재실행 금지 |
| 권한·스트림 | 실제 거부·승인 순서, 취소, 일부 실패와 미확인·잘못된·중복 호출에서 의도하지 않은 쓰기가 없음을 관측. 파괴적 사례는 오프라인 유지 |
| Claude 할당량 | 모의 Claude 할당량 거부에서도 Claude 모델 요청 없이 GPT가 작동. 실제 고갈 계정의 관측이 있으면 사용하되 로그인 만료·시작 실패와 구분. 할당량 초기화 대기 금지 |
| 격리·역할·사용량 | 프로필·제공자 상태 분리, 변경·재개 뒤 실제 worker 모델·사고 강도, 공개·승인 도구 경계 유지. 변환 기록·캐시·추론·worker·재시도·처리기 비용을 정확한 사용량 범위와 함께 보고 |
| 되돌리기 | 추가 Claude 모듈·세션 실행기를 끄면 기본 훅·Codex·사용자 설정·세션·자격 증명·가드를 유지하며 일반 동작 복구 |

검증 빌드, 원본 해시, 실제 모델·사고 강도, 인증 모드, 요청 횟수, 간결한 출력과 사용량 증빙으로
통과·실패·미검증을 기록한다. 필수 관측이 없으면 A10·A11은 미완료다. 한도 도달이나 실패로 새 배치·과금 경로·
인증 변경을 자동 승인하지 않는다.
