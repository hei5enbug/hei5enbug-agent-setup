# 모델 라우팅 검증

> 영어 원본: [model-routing-validation.md](model-routing-validation.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 실행 중 읽거나 사용하지 않는다.

2026-10-07에 검증했다. [기계 판독용 기록](model-routing-validation.json)에 소스 해시, 실제 모델 설정,
출력, 중복을 제외한 사용량과 미완료 인수 기준을 보존했다.
다음 단계와 인수 조건은 [남은 필수 작업](model-routing-remaining.ko.md)을 따른다.

| 검사 | 결과 |
|---|---|
| 전체 Python 테스트 | 종료 코드 0. 수집된 테스트 항목은 21,552개이며 Orca CLI를 사용할 수 있었다. |

| Claude 네이티브 Mod 테스트 | 6개 통과했다. 모델 요청 없는 기능 확인 테스트도 통과했다. |
| 잠금 파일과 Claude 매니페스트 | 통과했다. 기존 루트 컨텍스트와 한국어 frontmatter 경고는 남아 있다. |

형제 스킬 참조 검사기가 형제 스킬 경로와 두세 단계 상위로 이동하는 저장소 지침 링크를 구분하도록 수정했다.
기존 대상 존재 여부와 경로 이탈 검사는 유지했다.

## 반복 토큰 비교

유효한 비교에는 Codex CLI `0.160.1`, `gpt-6-luna`, `xhigh`, 기존 ChatGPT 구독과 읽기 전용 권한을 사용했다.
지침 재사용 문단만 달랐다. 양쪽은 최초 worker 라우팅을 판단한 뒤, worker 설정이 바뀐 상태에서 세션을 재개했다.
라우팅 출력은 같았고 모델 고정값, 근거, 대체 경로, 최신 상태 확인과 읽기 전용 실행에 대한 다섯 검사를 통과했다.

| 방식 | 입력·출력 토큰 합계 | 실행 시간 |
|---|---:|---:|
| 문단 없음 | 254,431 | 64.339초 |
| 문단 있음 | 235,420 | 49.145초 |

관측된 토큰 차이는 −19,011개(−7.47%)였다. 양쪽 모두 재개 시 변경 없는 라우팅 지침을 이미 재사용했다.
따라서 이 결과로 문단이 지침 로딩을 줄였다고 입증할 수 없다. 한 번의 비교로 실행 편차도 해소하지 못했다.
추가 필드 `prior_decisions_valid`는 과거와 현재 중 어느 범위를 뜻하는지 모호해 인수 근거로 사용하지 않았다.
비용 최적화는 채택하지 않았으며 A9는 미완료로 남았다.

합계에는 이 입력에서 메인 세션의 모든 입력·출력, 도구 결과와 최종 라우팅 인수가 포함된다.
평가 worker와 처리기 요청은 없었다. worker 구현·통합 비용과 Claude 네이티브 비용은 측정하지 못했다.
캐시는 입력에, 추론은 출력에 포함된다. 응답별 사용량을 한 번씩 합산했다.
재개한 CLI의 사용량은 누적값이므로 최초 CLI 합계에 더하면 안 된다.
시간은 두 프로세스의 실행 시간을 합산했다. 실행 사이 대기와 준비·채점은 평가 비용이다.

첫 비교는 한쪽이 고정된 입력보다 설치된 플러그인 소스를 먼저 읽어 제외했다.
절대 경로로 입력 범위를 고쳤으며 한도는 초기화하지 않았다. 종료된 배치는 제외한 실행을 포함해
사례 2개, 모델 시작 6회, 채점까지 514.192초를 사용했다. GPT 연결 제공자 요청은 없었고,
인증을 변경하거나 추가 과금을 활성화하지 않았다.

## 네이티브 GPT 연결

모델 요청 없는 임시 검사를 통해 Claude Code `2.1.291`의 선언을 생성했다.
`ToolInfo`는 여전히 `name`, `description`, `mcp`만 제공하고 `ToolDescribeInput`에도 입력 스키마가 없다.
재개 후 이전에 고정된 시스템 프롬프트에 접근할 수 있는지도 미검증이다.
[공식 Mods 문서](https://code.claude.com/docs/en/plugins/mods/create#get-type-definitions-for-your-version)는
설치된 선언을 해당 빌드의 권위 있는 근거로 사용하는 이유를 설명한다.

GPT 경로는 프로필·네트워크·추론 접근 전에 비활성 상태를 유지한다.
A10에는 지원되는 네이티브 picker·백엔드 라우팅과 세션에 고정된 프로필이 필요하다.
A11에는 실제 백엔드, 대화 기록, 재개, 취소, 권한, 할당량, 역할, 사용량과 되돌리기 관측이 필요하다.
Claude 구독을 다시 사용할 수 있어도 누락된 호스트 입력이 제공되지는 않는다.
현재 제약은 [GPT 구성 요소 가이드](claude-gpt.ko.md)를 참고한다.
