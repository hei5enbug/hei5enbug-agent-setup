# 남은 필수 작업

> 영어 원본: [README.md](model-routing-remaining.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 실행 중 읽거나 사용하지 않는다.

갱신일: 2026-10-07. 이 문서에는 미완료 요구 사항만 남겨 두었다.
완료한 구현은 `a833d1a`에 커밋하고 `origin/main`에 푸시했다.
이전 계획, 검증 원본 압축 파일과 원래 증거 기록은 외부 백업에 보존했다.
[백업 목록](model-routing-backup.json)에 위치, 파일과 검증한 SHA-256 값을 기록했다.
[최신 검증 기록](model-routing-validation.ko.md)과 [사용량 증빙](model-routing-validation.json)을 사용한다.

Codex 루프, 게이트웨이, 데몬, 추정한 스키마나 불완전한 시스템 컨텍스트로 네이티브 경로를 대체하지 않는다.
필수 조건을 검증할 때까지 프로필·네트워크·추론 접근 전에 거부하는 동작을 유지한다.

## A9: 다음 비교

2026-10-07의 유효한 비교는 토큰 254,431개와 235,420개(−7.47%), 시간 64.339초와 49.145초를 측정했다.
양쪽 출력은 다섯 라우팅 검사를 통과했다. 양쪽 모두 재개할 때 변경 없는 라우팅 지침을 이미 재사용했다.
따라서 이 차이로 후보 문단이 로딩을 줄였다고 입증할 수 없다.
실제 worker 구현·통합 비용과 Claude 네이티브 비용은 측정 범위 밖이다.
범위가 모호한 `prior_decisions_valid` 필드는 인수 근거로 사용하지 않는다.
측정 기록은 재사용하되 최적화를 채택하지 않는다.

새 비교 전에 두 방식의 실제 차이를 구분하는 작업 하나, 예상 출력과 모호하지 않은 품질 기준,
소스 버전, 권한, 모델·노력 수준과 완전한 비용 범위를 고정한다.
Skill Builder의 [기존 어댑터](../skills/skill-builder/references/execution-methods.ko.md)와 형식을 사용한다.
운영 고정값과 검증되지 않은 후보는 유지한다. 평가 프레임워크나 E1 노력 수준 실험은 필요하지 않다.
핵심·목록·본문·읽기 결과, 전달문, worker, 재시도와 인수·통합 비용을 중복 없이 측정한다.
재개한 CLI의 사용량은 누적값이다. 측정 누락이나 혼재된 결과가 있으면 A9는 미완료로 남는다.

같은 저장소 루트에서 시작 지침 기준은 Codex 7,668바이트, Claude 7,747바이트이며 9,000바이트 미만이다.
소스 바이트 변화만으로 실행 토큰 절감을 입증할 수 없다.

## 종료된 한도와 재개

두 배치는 모두 종료했다. 2026-10-06 배치는 사례 1개, 모델 시작 3회, 436.890초를 사용했다.
사용자는 2026-10-07에 추가 배치를 승인했으며 사례 2개, 모델 시작 6회 전부, 채점까지 514.192초를 사용했다.
첫 비교는 소스 컨텍스트가 섞여 제외했지만 한도에는 포함한다.
두 배치 모두 GPT 연결 제공자 요청은 0회였다. 인증 변경과 추가 과금은 없었다.
추가 실모델 작업에는 구체적인 새 승인이 필요하며 종료된 한도를 다시 사용할 수 없다.
사용자가 명시적으로 바꾸지 않는 한 새 한도도 사례 3개, 모델 시작 6회, 15분, GPT 연결 제공자 요청 6회 이하로 유지한다.

메인이 판단·통합·최종 검사를 맡는다. 변경 없는 기존 worker 구현과 유효한 검사 근거를 재사용한다.
사용자 설정, 설치된 캐시, 인증 정보, 권한 가드, 기본 훅과 메인·역할 고정값을 보존한다.
OpenCode를 설치하거나 실행하지 않는다. 릴리스 기준은 `v1.3.0`, 예정 버전은 `2.0.0`이다.
사용자는 2026-10-07에 커밋과 푸시를 승인했다. 두 작업이 미완료 인수 기준을 완료로 바꾸지는 않는다.

상세 계약을 이곳으로 옮기고 외부 백업을 검증한 뒤 로컬 `.plan` 폴더를 제거했다.
이 정리로 A9·A10·A11이 완료되지는 않는다. 근거로 인수 기준을 모두 충족하거나 사용자가 해당 범위를
명시적으로 취소·축소할 때까지 요구 사항을 보존한다.
