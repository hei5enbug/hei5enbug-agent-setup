# 서브에이전트 정책 결정

> 영어 원본: [subagent-policy-decision.md](subagent-policy-decision.md)
> 이 문서는 사람을 위한 비권위 한국어 참고 자료이며 실행 지침이 아니다.

**상태: 운영 기준을 채택하고 구현했으며, 두 호스트의 로컬 설치까지 완료했다.**
기존 비교 실험은 사용자 결정으로 종료했다. 당시 실행하지 않은 일정은 남은 구현 작업이 아니다.

## 결정과 근거

상황별 위임을 사용한다. 작업 배정 기준은 [공통 지침](../instructions/session/common.md),
담당 범위와 복구는 [구현 실행 규칙](../instructions/implementation-execution.md),
선택적 마무리 리뷰는 [독립 모델 검증](../instructions/independent-model-validation.md)에서 관리한다.

확보한 근거만으로는 모든 작업을 위임할 때 비용이나 품질이 더 좋아진다고 결론 내릴 수 없었다.
따라서 작업마다 조정 비용, 독립 실행 가능성, 메인 세션의 문맥 부담을 고려하는 기준을 채택했다.
이는 실무적인 판단이며 통계적으로 우위를 확인한 정책은 아니다.

## 반영한 변경

플러그인에 메인의 직접 처리, 범위가 한정된 위임, 안전한 메인 대체 처리와 사용자 승인 후 다른 계열 모델의
선택적 리뷰 1회를 반영했다. 실험에서 발견한 문서·계획 결함도 공통 지침에 반영했다.
영어 원본과 한국어 미러를 함께 갱신했다.

로컬 구조·회귀 검사를 통과했고 두 호스트에 설치한 실행 파일이 원본과 일치함을 확인했다.
이 검사는 배포할 규칙과 설치 상태를 확인한다. 변경한 정책의 실제 사용 비용·품질·모델의 지침 준수는 측정하지 않았다.

## 실험 종료

평가기, 상세 결과, 판정과 원래 계획은 SHA-256 목록·복원 안내와 함께 저장소 밖에 보관했다.
평가 전용 파일은 제품 트리에서 제거했다. 이 문서는 운영 결정과 한계를 남기며 실험 근거는 보관본에 유지한다.
새 유료 평가는 사용자의 명시적 결정이 필요하다. 이전 일정을 자동으로 재개하지 않는다.
