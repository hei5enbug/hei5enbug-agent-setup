# README 작성

> 영어 원본: [readme-writing.md](../../../instructions/readme-writing.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

처음 방문한 독자가 프로젝트의 목적과 자신에게 맞는지를 알고, 처음으로 유용한 결과를 얻을 수 있어야 한다.
[문서 규칙](documentation.ko.md)을 모두 적용한다. 이 문서는 README에만 필요한 규칙을 더한다.
번역본, 배지, 필수 절 등 저장소의 기존 관례가 아래 기본값보다 우선한다.

## 기본 순서

| 절 | 포함 조건 | 독자가 얻는 것 |
|---|---|---|
| 제목과 가치 설명 | 필수 | 무엇을 하는 프로젝트이고 누구를 위한 것인지 한 문장으로 설명한다. |
| 주요 기능 | 필수 | 이 프로젝트를 쓸 핵심 이유 몇 가지를 보여 준다. |
| 지원 플랫폼과 사전 조건 | 필수 | 독자가 실행하거나 사용할 수 있는지 판단하게 한다. |
| 설치와 첫 사용 | 필수 | 유용한 결과까지 가장 짧게 실행할 수 있는 방법을 준다. 실행하는 프로젝트가 아니면 내용을 사용하는 방법을 보여 준다. |
| 기능, 명령, 작업 흐름 | 선택지가 여러 개일 때 | 용도를 한 줄씩 설명해 선택을 돕는다. |
| 문서 안내 | 상세 문서가 있을 때 | 각 문서가 답하는 질문과 링크를 제공한다. |
| 개발 또는 기여 | 기여자에게 별도 출발점이 필요할 때 | 필수 검사를 제시하거나 기여 안내를 링크한다. |
| 도움말, 관련 자료, 라이선스 | 필수. 실제로 있는 경로만 적는다 | 도움받거나 기여할 곳, 사용 조건을 확인할 곳을 알려 준다. |

## 안내 페이지로 유지하기

- README는 프로젝트 안내 페이지로 유지한다. 한 화면, 대략 40줄보다 긴 설명이 필요한 주제는 링크한 별도 문서로
  옮긴다.
- 실행할 수 있는 빠른 시작을 참고 자료보다 앞에 둔다. 설치, 첫 사용, 고급 설정을 구분한다.
- 명령보다 먼저 사전 조건과 지원 플랫폼을 밝힌다. 복사해서 쓸 명령은 언어 태그가 있는 코드 블록에 넣는다.
- 2단계 제목이 여섯 개보다 많거나 여러 화면을 스크롤해야 하는 페이지에는 짧은 목차를 넣는다.
- 글로 보여 줄 수 없는 출력이나 화면을 전달할 때만 스크린샷이나 GIF를 넣고, 모든 이미지에 대체 텍스트를 단다.
- 구조를 바꿀 때 필수 명령과 절을 보존한다. 상세 내용은 링크와 번역본도 함께 옮기고, README에서 계속 찾아갈 수
  있게 한다.
- 배지는 독자에게 도움이 되고 저장소 관례에 맞을 때만 유지한다. 장식만을 위해 외부 서비스에 의존하는 배지를 추가하지 않는다.
- 상세 문서를 되풀이하거나 프로젝트 자체의 릴리스 버전을 적지 않는다. 변경 이력 절을 두는 대신 변경 로그나
  릴리스 노트를 링크하며, 이 규칙은 문서 규칙의 변경 이력 규칙보다 우선한다.
- 저장소 내부의 에이전트 규칙은 독자용 페이지가 아닌 해당 지침 원본에 둔다.
