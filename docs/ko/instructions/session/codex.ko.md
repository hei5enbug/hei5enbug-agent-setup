# Codex 전용 지침

> 영어 원본: [codex.md](../../../../instructions/session/codex.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

메인 세션의 계획 모드에서 계획한다.

호스트의 질문 도구 제한을 따른다. 도구가 있다고 blocking이나 자동 응답 방지가 보장되지는 않는다.

연결이 중단되면 [연결 복구](../connection-recovery.ko.md)를 읽는다.

에이전트나 모델 runner를 호출하기 전에 [Codex 에이전트 규칙](../codex-agents.ko.md)을 읽는다.
