# 여러 이슈에 걸친 개선 작업

> 영어 원본: [improvement-goals.md](../../../dev-rules/improvement-goals.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

소유자 결정(2026-11-24). 이 저장소에서 여러 이슈에 걸친 개선 작업에 적용한다.

1. 우선순위와 효율에 따라 작업 순서를 정한다.
2. 난이도가 높으면 `claude-fable-5-2` 서브에이전트가 `high` effort로 먼저 계획을 작성하고, `gpt-6.2-astra`가
   `xhigh` effort로 한 번 검토한 뒤, 그 검토로 계획을 고치고 나서 시작한다.
3. 결함 수정과 필요한 개선을 먼저 구현하고, 구현한 부분을 검증한다.
4. 반복 실행, 통합 회귀 검사, 상세한 변경 전후 비교 등은 후속 이슈에서 측정한다. 후속 이슈에 실행할 명령과
   비용을 적는다. 판정에 그 측정이 필요하면 후속 이슈에서 판정할 때까지 결론을 보류한다.
