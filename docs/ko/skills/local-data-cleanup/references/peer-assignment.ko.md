# 두 번째 판정 지시문

> 영어 원본: [peer-assignment.md](../../../../../skills/local-data-cleanup/references/peer-assignment.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

자리표시자를 채운 뒤 이 텍스트를 다른 호스트의 읽기 전용 에이전트 하나에게 준다. survey의 candidate를 `id`, `kind`, `what`,
`paths`, `size`, `newest_mtime` 키를 가진 객체의 JSON 목록으로 붙여 넣는다. report-only와 protected 항목은 뺀다.

```text
너는 읽기 전용 검토자다. 어떤 파일도 삭제, 이동, 쓰기, 권한 변경을 하지 마라. 다른 에이전트도 시작하지 마라. 영어로 답하라.

다른 에이전트가 이 컴퓨터의 Claude Code와 Codex 로컬 데이터를 조사했고, 아래 candidate를 삭제해도 안전하다고 나열했다.
각 항목을 직접 확인하되, 폴더 목록 보기, 링크 대상과 수정 시각 읽기, 호스트의 설치된 플러그인 목록 읽기처럼 읽기 전용으로
확인하라. 대화 기록이나 세션 기록의 내용은 절대 읽지 마라. 조사 결과의 주장은 믿지 말고 확인하라.

알려진 루트: <survey의 루트: 이름과 경로>
오래된 세션 기록의 나이 기준: <N>일. 최근 구간: <H>시간. 현재: <ISO 시각>.
candidate 목록: <JSON 목록>

각 candidate에 대해, 다음 모든 요건이 성립할 때만 `delete`로 답하라:
1. 모든 경로가 실제로 존재하며, kind와 설명이 말하는 그대로다.
2. 대체된 릴리스나 플러그인 버전은, `current` 링크나 런처 링크, 또는 설치된 플러그인 목록이 쓰는 버전보다 오래됐고
   그 버전 자체가 아니다.
3. 어떤 경로도 상태 데이터베이스, 자격 증명, 설정, 히스토리, 메모리 파일이거나 그런 파일을 담고 있지 않다.
4. 경로 아래의 어떤 것도 최근 구간 안에 바뀌지 않았고, 오래된 세션 기록은 나이 기준보다 오래됐다.
5. 어떤 경로도 알려진 루트 밖으로 해석되지 않는다.
6. 실행 중인 세션이 아직 그것을 쓰고 있다고 시사하는 것을 찾지 못했다.

요건 하나라도 성립하지 않으면 `keep`으로, 확인하지 못한 요건이 있으면 `unknown`으로 답하라. 사유는 한 문장으로 적어라.

다음 JSON 객체만 반환하라:
{"host": "<claude or codex: the host you run on>", "model": "<your model ID>",
 "verdicts": [{"id": <candidate id>, "verdict": "delete" | "keep" | "unknown", "reason": "<one sentence>"}]}
```
