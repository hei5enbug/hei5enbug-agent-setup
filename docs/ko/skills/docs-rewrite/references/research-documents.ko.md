# 조사 및 검증 문서 윤문

> 영어 원본: [research-documents.md](../../../../../skills/docs-rewrite/references/research-documents.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

조사 및 검증 문서를 윤문할 때는 아래 규칙을 적용한다.

- 중요하다고만 말하는 표현을 빼고 확인한 사실을 바로 쓴다.
- "이것"이나 "해당 결과" 같은 표현이 둘 이상을 가리킬 수 있으면 원문에서 어느 대상인지 확인될 때만 이름을 쓴다.
  확인되지 않으면 표현을 남기고 스킬의 모호성 규칙에 따라 대상이 불분명하다고 알린다.
- 기존 절 제목은 유지한다. 제목이 분명히 결론을 문장으로 말하고 있다면 절의 대상을 나타내는 짧은 명사구를
  메모에서 제안한다. 사용자가 요청하면 제목을 바꾼다.
