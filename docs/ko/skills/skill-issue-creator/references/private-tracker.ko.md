# 비공개 트래커의 상세 정보

> 영어 원본: [private-tracker.md](../../../../../skills/skill-issue-creator/references/private-tracker.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

`target.public`이 false인 초안에 적용하는 규칙이다. 그런 이슈의 초안을 쓰기 전에 읽는다.

담당 플러그인에서 작업하는 코딩 에이전트가 이슈를 읽으므로, Proposal과 Acceptance criteria를 포함한 모든 절에
작업에 도움이 되는 세부 정보를 모두 넣는다.

- 실제 티켓 키, 저장소 이름, 저장소 내부 파일 경로, 브랜치 이름, 커밋 해시
- 관련된 다른 플러그인, 제품, 서비스의 이름과 각각이 빈틈과 맺는 관계
- 인수 기준을 작성된 그대로 실행할 수 있도록 가상 값 대신 실제 값. 담당 저장소가 평가 픽스처에 담을 수 있는 내용을
  제한하는 경우는 예외이며, 아래 마지막 규칙을 따른다.

사례의 실제 티켓 키, 저장소, 다른 플러그인의 이름을 Proposal 안에도 적는다. 규칙이 적용되는 곳에 적거나, 규칙이
어느 티켓, 저장소, 플러그인에서 나왔고 어디에 적용되는지 밝히는 줄에 적는다. Observations와 Evidence에만 적는 것으로는
부족하다.

트래커와 관계없이 다음은 계속 제외한다.

- 비밀, 자격 증명, 토큰, 비밀번호, 키, 개인 정보
- 로컬 절대 경로, 홈 폴더, 사용자 이름. 경로는 대신 저장소 기준 상대 경로로 쓴다.
- 콘텐츠 규칙 파일이 제외하는 모든 문장. 그 파일은 계속 이슈의 내용을 제한하며,
  비공개 트래커라고 해서 그 파일이 제외한 내용을 허용하지 않는다.

비공개 트래커에는 규칙이 둘 더 있다.

- 초안이 페이지, 파일, 메시지를 인용한다면 사람의 이름 없이 인용한다(이름이 들어 있는 제목 등). 등록하기 전에 초안에서 1단계에서
  모은 각 사람과 모든 이메일 주소를 검색하고, 하나도 남지 않을 때까지 다시 쓴다.
- 담당 저장소의 지침 파일(`AGENTS.md`, `CLAUDE.md` 등)을 확인한다. 그 지침이 평가 픽스처에 담을 수 있는 내용을 제한한다면,
  실제 사례는 Observations와 Evidence에 두고, Acceptance criteria에는 픽스처가 그 지침이 허용하는 값으로 사례를 대체한다고 쓴다.
