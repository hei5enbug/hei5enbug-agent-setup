# 공개 트래커의 상세 정보

> 영어 원본: [public-tracker.md](../../../../../skills/skill-issue-creator/references/public-tracker.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

`target.public`이 true일 때 초안에 적용하는 규칙이다. 그런 이슈의 초안을 쓰기 전에 읽는다. 공개 트래커는 누구나 읽을 수
있으므로 초안에 비공개 세부 정보를 넣지 않는다. 모든 쓰기 전에는 여전히 공개 정보 유출 검사를 실행한다.

- Acceptance criteria는 `demo-a`, `example.com`, `/tmp/work`, `ABC-123` 같은 가상 값으로 쓴다.
- 사례의 식별자는 Observations와 Evidence에만 넣는다.
- 내부 URL, 호스트 이름, 계정 식별자와 비공개 조직, 제품, 저장소, 플러그인, 사람, 채널의 이름은 제외한다.
- 제안에는 담당 플러그인과 공개 도구의 이름만 쓴다.
  다른 플러그인은 역할로 설명하여, 담당 플러그인이 자신을 기반으로 만든 플러그인의 이름을 알 필요가 없게 한다.
- Proposal과 Acceptance criteria에서 스킬의 1단계에 나온 식별자를 하나씩 검색하고, 전체 초안에서 제외해야 할 값을 모두
  검색한다. 하나도 남지 않을 때까지 고쳐 쓴다.
