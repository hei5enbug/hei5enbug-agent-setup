# 조사 보고서 작성

> 영어 원본: [SKILL.md](../../../../skills/research-report-writer/SKILL.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

조사나 데이터 분석 결과를 문서로 정리해 달라는 등 요청이 모호하면 먼저 이 스킬을 사용할지 한 번
묻는다. 답을 받기 전에 자료를 살피거나 문서를 쓰지 않는다. 사용자가 동의한 경우에만 이 스킬을
불러온다. 사용자가 이 스킬을 지명하거나 데이터로 질문에 답하는 문서나 주장을 검증하는 문서를
명시적으로 요청하면 바로 시작한다. 그 밖의 요청에는 이 스킬을 사용하거나 추천하지 않는다.

보고서를 쓰기 전에 [조사 및 검증 문서](../../instructions/research-documents.ko.md)를 읽는다.

1. 사용자가 정한 질문을 쓰거나, 어떤 데이터를 읽고 분석할지 계획하기 전에 사용자와 질문을 정한다.
2. 데이터를 읽고 분석한 뒤 결과를 검증한다.
3. 로컬 보고서는 최종 검토 전에 요청받은 경로에 저장한다. 포그라운드에서 각 검토 결과를 기다리고
   같은 파일에 수정 사항을 반영한다. 답변에서는 파일을 짧게 안내하고 사용자가 결정할 검토 의견이
   있으면 함께 묻는다.

- 검증에 실패했거나 아직 검증을 마치지 않은 선택지, 결과, 개선안, 제안은 보고서 어디에서도
  언급하지 않는다. 제외했다는 설명도 넣지 않는다. 사용자가 요청하면 미검증으로 표시하고 검증한
  결과와 표에서 분리한다.
- 방법, 선택지, 정의를 비교할 때는 같은 지표로 측정한 결과를 표 하나에 담는다. 추천한 선택지도
  포함해 각 선택지가 어떻게 동작하고 데이터에서 무엇을 확인했는지 설명한다.
- 정한 기준에 따라 데이터에서 사례를 고른다. 각 사례에 기준과 그림을 함께 보여 준다.
