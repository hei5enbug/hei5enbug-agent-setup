# 조사 보고서 작성

> 영어 원본: [SKILL.md](../../../../skills/research-report-writer/SKILL.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

데이터로 질문에 답하거나 주장을 검증하는 보고서를 쓴다. 사용자가 이 스킬을 지명하거나 조사 또는
검증 문서를 직접 요청하면 묻지 않고 시작한다. 조사나 데이터 분석 결과를 문서로 정리해 달라는 등
요청이 모호하면 분석하거나 쓰기 전에 `research-report-writer`를 사용할지 한 번 묻는다. 사용자가
동의하면 시작한다. 그 밖의 요청에는 이 스킬을 사용하거나 추천하지 않는다.

1. 보고서가 답할 질문을 정한다. 사용자가 이미 정한 질문은 그대로 쓴다. 아직 정해지지 않았다면
   어떤 데이터를 읽고 어떻게 답할지 계획하기 전에 사용자와 질문을 정한다.
2. 읽기로 한 데이터를 살피고 분석한 뒤 결과를 확인한다.
3. 확인한 결과로 보고서를 쓴다.

보고서를 쓰기 전에 [조사 및 검증 문서](../../instructions/research-documents.ko.md)를 읽는다.

- 검증에 실패했거나 아직 검증을 마치지 않았거나 시작하지 않은 결과, 개선안, 제안은 뺀다. 후속
  작업이나 후보 목록에도 넣지 않는다. 사용자가 요청하면 미검증으로 표시하고 확인한 결과와
  구분해 넣는다.
- 방법, 선택지, 정의를 둘 이상 비교할 때는 같은 지표로 측정한 결과를 표 하나에 담는다. 각
  선택지가 어떻게 동작하고 데이터에서 무엇을 확인했는지 설명한다. 추천한 선택지도 같은
  방식으로 설명한다.
- 개별 사례를 보여 줄 때는 기준을 정하고 데이터에서 사례를 고른다. 각 사례에 기준과 그림을 함께
  둔다. 가장 느린 요청을 골랐다면 그 요청의 추적 화면을 함께 보여 준다.
