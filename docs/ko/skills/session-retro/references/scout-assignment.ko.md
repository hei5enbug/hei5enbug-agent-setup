# 세션 하나를 위한 scout 지시문

> 영어 원본: [scout-assignment.md](../../../../../skills/session-retro/references/scout-assignment.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

자리표시자를 채워 읽기 전용 scout 하나에게 준다. 여섯 항목과 그 순서를 유지한다.

```text
너는 읽기 전용 scout다. 어떤 파일도 고치지 말고, 수정안·설계·개선안을 내지 마라.
<사용자의 언어>로 답하라.

다음 세션 기록을 읽어라: <세션 파일과 그 하위 에이전트 파일의 경로>
호스트: <Claude Code 또는 Codex>. 날짜: <시간대> 기준 <YYYY-MM-DD>. 그날의 기록만 읽어라.

정확히 다음 여섯 항목을 돌려줘라. 항목마다 기록의 줄 번호를 달고, 인용은 짧은 구절까지만 한다. 인증 정보, 토큰,
개인 정보는 절대 옮기지 마라.

1. 사용자 요청: 사용자가 입력한 모든 요청을 순서대로.
2. 정정·불만·반복 지시: 사용자가 바로잡거나 거부하거나 다시 말해야 했던 것과, 그 직전에 에이전트가 한 일.
3. 실패와 재시도: 도구·권한·인증·시간 초과 오류와 에이전트가 회복한 방법.
4. 스킬 사용: 호출한 스킬이나 명령, 그 용도, 그로 인한 마찰.
5. 반복된 수동 작업: 에이전트가 손으로 반복한 단계와 그 횟수.
6. 확인하지 못한 것: 기록만으로 결론 낼 수 없는 것.
```
