# Codex 릴리스 업데이트

> 영어 원본: [codex-releases.md](../../../../../skills/orca-plugin-refresh/references/codex-releases.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

스크립트는 `update` 실행에서 첫 Codex 명령을 보내기 전에 선택된 Git 마켓플레이스마다 원격의 최신
`v<major>.<minor>.<patch>` 태그를 찾아 `config.toml`의 ref에 쓴다. 미리 보기 태그는 제외한다.
`codex plugin list`만으로도 자동 업데이트가 일어날 수 있으므로 설치된 버전을 먼저 기록한다.
ref를 고르기 전 최초 설치 게이트가 Codex를 보류하면 ref를 그대로 두고 설정된 Git 마켓플레이스에 대해
Codex 명령을 실행하지 않는다.

릴리스 태그가 없는 마켓플레이스는 ref를 유지하고 `codex_marketplace_untagged`를 받는다. 스크립트는 그 마켓에
명시적인 업그레이드나 설치를 실행하지 않고 다른 마켓플레이스는 계속 처리한다. 태그가 생기거나 사용자가 ref를
정하기 전까지 Codex를 시작하면 미출시 커밋이 설치될 수 있음을 보고한다. 설정을 읽거나 갱신하지 못하면 해당 실행의
Codex 명령을 중단한다.

## 훅 신뢰

`codex_hooks_need_trust`는 신뢰되지 않은 훅이 남았거나 검증하지 못했다는 뜻이다. 이 플러그인은 자기 훅을 신뢰하기
전에 변경 없는 공식 체크아웃인지 확인하는 기존 동작을 유지한다. HEAD는 공식 원격이 `main`이나 `v*` 태그로
알려 주는 커밋이거나 현재 `main`에 포함된 커밋이어야 한다. 동반 플러그인의 훅은 다음 조건을 모두 통과할 때만
다시 묻지 않고 신뢰한다.

- 각 훅이 그 동반 플러그인을 가리키고, 원본 파일과 명령의 대상이 설치 폴더 안에 있다. 셸 명령 연결이나 변경 가능한
  Git·설치 메타데이터를 사용하지 않는다.
- 설치 표식의 source는 설정된 마켓플레이스 원본과 같고, ref는 고정한 태그 이름과 같으며, revision은 원격에서
  현재 그 태그가 가리키는 커밋과 같다.
- 설치된 모든 파일이 해당 커밋의 플러그인 디렉터리와 같다. Git 메타데이터와 마켓플레이스 설치 표식을 제외하면
  추가 파일이 없어야 한다. 심볼릭 링크와 지원하지 않는 플러그인 원본은 거부한다.

스크립트는 Codex의 `config/value/write`로 현재 해시를 신뢰하고 `hooks/list`로 확인한다.
성공하면 `codex_hooks_trusted: true`를 보고한다. 실패하면 이유와 함께 `codex_hooks_need_trust`를 보고하고
사용자에게 `/hooks`에서 남은 훅을 검토하도록 요청한다. Codex는 신뢰될 때까지 그 훅을 건너뛴다.

## 교체된 폴더를 쓰는 세션

`apply`는 턴을 진행한 Codex 세션에 대해 프로세스 시작 시각과 선택한 플러그인의 설치 표식 시각을 비교한다.
설치 폴더보다 먼저 시작한 프로세스는 `skipped`, `codex_plugin_folder_replaced`, `resume_approval_needed`로
보고하며 compact 명령을 보내지 않는다. 재개한 프로세스를 포함해 설치 뒤 시작한 프로세스와 턴을 진행하지 않은
세션은 제외한다. 새로고침되지 않은 세션으로 보고하고 6단계에서 재개를 제안한다.
