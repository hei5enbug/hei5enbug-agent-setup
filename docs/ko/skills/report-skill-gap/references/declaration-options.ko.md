# 선언 옵션

> 영어 원본: [declaration-options.md](../../../../../skills/report-skill-gap/references/declaration-options.md)
> 이 문서는 사람을 위한 비권위 한국어 번역본이다. 에이전트 실행 시 읽거나 사용하지 않는다.

선언이 해당 옵션을 사용할 때만 적용되는 규칙이다. 작업 흐름의 4단계 전에 이 파일을 읽는다.

## `github`이 아닌 종류의 트래커

4단계의 중복 검색, 7단계의 생성, 8단계의 다시 읽기에 하나의 경로를 쓴다.
선언된 위치에 닿는 트래커의 연결된 도구가 있으면 그 도구를 쓴다.
없으면 이미 인증된 해당 트래커 종류의 공식 CLI를 쓴다. 예를 들어 Azure DevOps 위치에는 `az boards`, GitLab에는 `glab`이다.
로그인하지 않으며, 자격 증명을 전달하거나 출력하거나 저장하지 않는다.
어느 경로도 선언된 위치에서 세 가지를 모두 할 수 없으면 초안을 보여 주고 등록하지 않는다.

## HTML 본문

- 초안에서 절 제목에는 `<h2>`, 목록에는 `<ul>`이나 `<ol>`, 코드에는 `<code>`를 쓴다.
- 8단계에서 렌더링된 항목에 `<h2>` 같은 원시 태그나 `&lt;` 같은 이스케이프된 엔티티가 보이지 않는지 확인한다.

## 태그 템플릿

`target.label_mode`가 `template`일 때 적용한다.

- `target.labels`를 `;`로 나누고 `{skill}`을 담당 스킬의 이름으로 바꾼다. 지침 파일이면 확장자를 뺀 파일 이름을 쓴다.
  나온 태그를 모두 순서대로 적용한다.
- 새 스킬 제안에서는 `{skill}`이 제안하는 스킬의 이름 다음에 태그 `new-skill`이 오는 형태로 바뀐다.
- 6단계에서는 미리 보기가 라벨을 보여 주는 자리에 태그를 보여 준다.
- GitHub에서는 7단계에서 태그마다 `--label`을 반복한다.
- 8단계에서 모든 태그를 확인한다.
